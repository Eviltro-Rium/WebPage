# 🐶 Otto

- **初始血量**：100
- **被动**：进攻时伤害>4可消耗1层【暴击】使攻击不可防御。多人模式下当Serenity是Otto队友时，Serenity受到超过6🗡️伤害时，超出部分由Otto承担，且自动防御1/2（向上取整）点，Serenity仍可以对6点伤害做出防御。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 4🗡️ |
| 2️⃣ | 3🗡️，获得1层【守护】 |
| 3️⃣ | 把牌库的一张牌放入判定区（结束后放入弃牌库底）。造成判定牌对应点数（道具牌视作4点）🗡️，如果伤害>4，则自伤2🗡️，并获得1层【暴击】 |
| 4️⃣ | 翻开牌库顶两张牌进行判定（判定后放回牌库顶）：两张均为数字牌→造成数字之和🗡️；1张道具牌→造成另一张数字½（向上取整）🗡️（不可防御）；两张道具牌→吸取3❤️（不可防御） |
| 5️⃣ | 再选择打出一张数字牌进行判定（结束后放回弃牌库顶），若判定为🔴🟡🔵🟢，则造成对应数字点🗡️；若为⚪，则恢复对应点❤️，并获得1层【暴击】（跳过防御） |
| 6️⃣ | 造成自身血量/10（向上取整）点🗡️（双雄模式改为/20） |
| 7️⃣ | 6🗡️，自伤1🗡️，获得1层【暴击】 |
| 0️⃣ | 4🗡️。每消耗1层【暴击】额外+3🗡️并自伤2🗡️。无【暴击】消耗时，该伤害不可防御 |


## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 防御1/2（向上取整）点🗡️；可以使用2层【暴击】来返还这防御的伤害 |
| 2️⃣ | 反击2🗡️，获得1层【守护】 |
| 3️⃣ | 恢复2❤️，施加2层【流血】 |
| 0️⃣ | 获得5层【守护】，反击相同点🗡️ |


## 【暴击】

- 正面buff，堆叠上限为2层
- 拥有该buff的玩家进攻时，如果造成伤害数值超过4点（防御进行前，不含流血伤害）时，可以花费一层【暴击】来把攻击变成不可防御
- 本身不可防御的技能，不能使用该buff


## 备注

- 🗡️=伤害点数，❤️=恢复生命值，🃏=卡牌
- 🧪=药水牌（白色道具牌，恢复5❤️+搭桥，可匹配任意颜色）
- +3🃏=抽3张的白色道具牌（搭桥，可匹配任意颜色）
- 搭桥可连续使用（黑牌→🧪→+3→黑牌…）
- 数字牌和道具牌互斥
- 0️⃣为AOE技能，1v2模式中对所有对手生效
