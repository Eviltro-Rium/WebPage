# 🐻‍❄️ Leon

- **初始血量**：90
- **被动**：免疫灼烧。灼烧buff最高4层。拥有该buff的玩家，在进攻结束后，有几层灼烧受到几点伤害，然后去除一层灼烧。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 施加2层【灼伤】（跳过防御） |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 3🗡️，施加1层【灼伤】 |
| 4️⃣ | 5🗡️，目标有【灼伤】→跳过防御 |
| 5️⃣ | 4🗡️，目标有【灼伤】+2🗡️ |
| 6️⃣ | 抽1🃏并公示判定：1️⃣-7️⃣数字牌（含白色数字牌）→造成对应数字🗡️，加入手牌；0️⃣/道具牌→加入手牌+抽1🃏+2层灼伤（跳过防御） |
| 7️⃣ | 弃目标1🃏，6🗡️，2层【灼伤】 |
| 0️⃣ | 对所有对手+1【灼烧】，弃对手合计2🃏，7🗡️（不可防御），每有1个对手存活自伤2🗡️（跳过防御） |


## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 施加1层【灼伤】给攻击方，恢复2❤️ |
| 2️⃣ | 反击½（向上取整）所受🗡️，抽1🃏 |
| 3️⃣ | 格挡½（向上取整）所受🗡️，抽1🃏 |
| 0️⃣ | 攻击方弃掉所有牌，双方各受等量🗡️ |


## 备注

- 🗡️=伤害点数，❤️=恢复生命值，🃏=卡牌
- 🧪=药水牌（白色道具牌，恢复5❤️+搭桥，可匹配任意颜色）
- +3🃏=抽3张的白色道具牌（搭桥，可匹配任意颜色）
- 搭桥可连续使用（黑牌→🧪→+3→黑牌…）
- 数字牌和道具牌互斥
- 0️⃣为AOE技能，1v2模式中对所有对手生效
