# 冒险模式 · 配饰图鉴

配饰获得后**永久生效**，不占 6 格道具槽，也**不会消耗**。在地图侧栏与对战界面均可查看已持有的配饰列表。

## 使用规则概览

| 特性 | 说明 |
|------|------|
| 数量 | 无上限（可重复获得同名配饰，但多数效果不叠加，见下文） |
| 生效时机 | 获得瞬间生效；部分效果在战斗结算或造成伤害时触发 |
| 使用方式 | 无需手动使用，被动常驻 |
| 与一次性道具 | 商店刷新、战斗掉落等「随机道具」池**不含**配饰 |

## 铁匠铺

- **出现**：第 1–4 层地图支路
- **进门费**（仅首次进入该房间）：第 1 层 **1** 金币、第 2 层 **2** 金币、第 3 层 **3** 金币、第 4 层 **4** 金币
- **槽位**：3 个配饰槽，随机展示可兑换配饰；槽位下方显示所需兽元图标与文字
- **兑换**：消耗对应兽元获得配饰（万能可替代）

## 智慧项链（`WisdomNecklace`）

- **兑换**：3水 + 1本 + 1草
- **效果**：每次**战斗胜利**后，从玩家牌库抽取 **2** 张牌加入手牌（牌库不足则抽到手牌上限为止）
- **触发时机**：胜利回血与房间清除之后、战斗基础奖励结算之前
- **叠加**：重复获得不会增加补牌数量（仍按定义抽 2 张）

---

## 火焰之拳（`FlameFist`）

- **兑换**：4火 + 1本
- **效果**：玩家在**防御阶段发动防御技能**时，对攻击者额外施加 **1** 层灼伤
- **触发条件**：
  - 仅冒险对战（`AdventureBattleEngine`）
  - 玩家选择防御（非跳过）
  - 防御牌无需颜色选择或颜色已指定（黑牌搭桥需先选色，选完再次进入防御时触发）
- **叠加**：重复获得不会增加灼伤层数（仍为 1 层）
- **备注**：对手为 Leon 时仍受灼伤免疫规则约束

---

## 兽元袋（`BeastBag`）

- **兑换**：3本 + 2草
- **效果**：兽元储存上限由默认 **8** 提升至 **12**
- **触发时机**：获得配饰时立即重算上限；超出部分不可再获得新兽元
- **叠加**：多个兽元袋仍只取最高上限（12），不会累加

---

## 生命核心（`LifeCore`）

- **兑换**：3草 + 1水 + 1本
- **效果**：每次在**普通房、挑战房、Boss 房**战斗胜利后，在基础胜利回复之外**额外恢复 3 点生命**（不超过上限）
- **触发时机**：基础胜利回复之后、智慧项链补牌之前
- **叠加**：重复获得不会增加回复量（仍为 3 点）

---

## 冷冻激光（`FreezeLaser`）

- **兑换**：3水 + 1万能
- **效果**：玩家进攻造成**数值伤害**时，对对手施加**冷冻**（跳过对手下次出牌）
- **触发条件**：
  - 仅冒险对战（`AdventureBattleEngine`）
  - 伤害量 **> 0**
  - 不含流血结算、吸血等特殊伤害类型
  - **每次进攻**至多触发 1 次
- **携带上限**：1 个

---

## 能量盾（`EnergyShield`）

- **兑换**：3草 + 2本
- **效果**：玩家**进攻开始前**获得 **1** 层守护（用于格挡对手反击伤害）
- **触发条件**：
  - 仅冒险对战（`AdventureBattleEngine`）
  - 玩家打出非道具进攻牌时
  - **每次进攻**至多触发 1 次
- **叠加**：最多 2 个，效果叠加（2 个 = 2 层守护）

---

## 正义之锤（`JusticeHammer`）

- **兑换**：2火 + 2水 + 1本
- **效果**：所有有伤害的技能伤害 **+1**
- **触发时机**：攻击伤害进入攻击修正阶段时（在攻击修正道具、暴击判定之前加成）
- **携带上限**：1 个

---

## 净化水晶（`PurifyCrystal`）

- **兑换**：2草 + 2水 + 1本
- **效果**：打出**绿牌或蓝牌**时，选择自己或对手的一个 buff 清除一层
- **触发时机**：攻击修正与暴击判定之后、AI 防御之前
- **触发条件**：
  - 仅冒险对战（`AdventureBattleEngine`）
  - 进攻牌的实际颜色为绿色或蓝色（含黑/白牌指定颜色）
  - 自己或对手至少有一个可清除的 buff（灼烧/冷冻/流血/中毒/守护/飞翔/暴击）
- **携带上限**：1 个

---

## 恶魔契约（`DemonPact`）

- **兑换**：1火 + 1水 + 1草 + 1万能
- **效果**：选牌阶段可自伤 **3** 点生命抽取 **1** 张牌
- **触发时机**：玩家进攻选牌阶段（`PLAYER_PLAY`）或防御选牌阶段（`PLAYER_DEFEND`，含不可防御等待）
- **使用方式**：点击"恶魔交易"按钮主动触发（类似道具使用）
- **限制**：
  - 每个选牌阶段限用 **1** 次
  - 生命值需 > 3 点
  - 牌库需有牌可抽
- **携带上限**：1 个

## 获取方式（当前实现）

| 途径 | 说明 |
|------|------|
| 商店 | 第 6 槽随机配饰，**15** 金币购买，刷新 **2** 金币 |
| 铁匠铺 | 3 槽随机配饰，兽元兑换（见上表） |
| 铁匠铺 | 3 槽随机配饰，兽元兑换（见上表） |
| 战斗胜利 | 基础奖励池**不含**配饰 |

商店与铁匠铺均可获得配饰；商店为 **20** 金币购买，铁匠铺为兽元兑换。
