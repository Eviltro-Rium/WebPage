# 城堡场景 · 怪物图鉴

普通怪物通常在 Stage 1-4 均可出现；城堡幽灵、哥布林等标注为 Stage 2 起出现的怪物除外。怪物按 stage 逐级强化：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

---

## 城堡幽灵（CastleGhost）

**出现条件**：仅从 Stage 2 开始有几率出现

**生命值**：24

**进攻**：
- 出 1/2/3 牌：造成 **3** 点伤害，获得 1 层【飞翔】
- 出 4/5/6 牌：若打出后手上正好剩 1 张牌，按该牌点数的 **1.5 倍（向上取整）**造成伤害；若没有正好剩 1 张牌，本轮空过

**防御**：
- 出 1/2/3 牌：投掷 12 面骰，投出 1-4 时免疫伤害和 buff；玩家仍可给自己叠加增益

**Stage 强化**：
- **Stage 3**：4/5/6 牌改为按剩余手牌点数的 **2 倍**造成伤害
- **Stage 4**：防御骰投出 1-6 即可触发免疫

## 萤火虫（CastleFirefly）

**生命值**：18

**进攻**：
- 出 1/2/3 牌：造成 **2** 点伤害，获得 1 层【飞翔】
- 出 4/5/6 牌：造成 **4** 点伤害，施加 1 层【致盲】（持续；致盲期间不能使用一次性道具）

**防御**：
- 出 1/2/3 牌：格挡 `向上取整(1 + 玩家当前一次性道具数量 / 2)` 点伤害

**Stage 强化**：
- **Stage 2**：生命上限 +6（24）
- **Stage 3**：所有进攻伤害 +1
- **Stage 4**：防御格挡改为 `1 + 玩家当前一次性道具数量`

---

## 狼（CastleWolf）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：造成 **4** 点伤害
- 出 4/5/6 牌：造成 **6** 点伤害

**防御**：
- 出 1 牌：格挡 1 点伤害
- 出 2 牌：格挡 2 点伤害
- 出 3 牌：格挡 3 点伤害

**Stage 强化**：
- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有伤害 +1
- **Stage 4**：格挡 +1

## 狐（CastleFox）

**生命值**：18

**进攻**：
- 出 1/2/3 牌：造成 **不可防御** 的对应点数伤害（出1→1伤害，出2→2伤害，出3→3伤害）
- 出 4/5/6 牌：造成 **玩家当前手牌数** 点伤害（可防御）

**防御**：
- 出 1/2/3 牌：恢复 **2** 点生命

**Stage 强化**：
- **Stage 2**：生命上限 +6（24）
- **Stage 3**：1/2/3 牌伤害 +1
- **Stage 4**：恢复生命改为 3 点

- 出 4/5/6 牌：造成 **4** 点伤害，施加 **1** 层流血

## 虎（CastleTiger）

**先手攻击**：战斗开始时虎先手攻击

**进攻**：
- 出 1/2/3 牌：造成 **2** 点伤害，施加 **1** 层流血
- 出 4/5/6 牌：造成 **对应点数** 伤害（出4→4伤害，出5→5伤害，出6→6伤害）

**防御**：

- 出 2 牌：反击 **2** 点伤害
- 出 3 牌：反击 **3** 点伤害

**Stage 强化**：
- **Stage 2**：生命上限 +4（24）
- **Stage 3**：1/2/3 牌伤害变为 **不可防御**

## 鸦（CastleCrow）

**进攻**：
- 出 1/2/3 牌：造成 **3** 点伤害，恢复 **1** 点生命

- **Stage 3**：所有伤害 +1

## 蝠（CastleBat）

## 哥布林（DungeonGoblin）

**生命值**：27

**出现条件**：仅在 **Stage 2/3/4** 刷出

**被动**：哥布林在进攻阶段打出数字 **1** 卡牌时触发：
- **Stage 2**：玩家损失 **1** 金币
- **Stage 3/4**：玩家损失 **1** 件随机道具

**进攻**：
- 出 1/2/3 牌：造成 **2** 点 **不可防御** 伤害
- 出 4/5/6 牌：造成 **5** 点伤害，获得 **1/2/3** 层守护（出4→1层，出5→2层，出6→3层）

**防御**：
- 出 1 牌：恢复 **1** 点生命
- 出 2 牌：恢复 **2** 点生命
- 出 3 牌：恢复 **3** 点生命

**Stage 强化**：
- **Stage 3**：伤害 **+1**
- **Stage 4**：防御恢复生命 +1（出1→2，出2→3，出3→4）

## Boss · 隐之避役（CastleChameleon）

**生命值**：40  
**手牌**：3 张  
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**中毒（新负面）**：
- 堆叠上限 **3**
- 持有中毒时，**进攻回合开始前**受到等同于中毒层数的伤害
- 层数不随时间自然减少（持续），可用净化移除

**进攻**：
- 出 1/2/3 牌：分别造成 **1/2/3** 点 **不可防御** 伤害
- 出 4/5/6 牌：造成 **3** 点伤害，施加 **1** 层中毒
- 出 0 牌：造成 **2** 点 **不可防御** 伤害，获得 **2** 层守护，施加 **2** 层中毒

**击败奖励**：战胜 Boss 后玩家额外恢复 **10** 点生命（普通战斗仍为 3 点）

**防御**：
- 出 1/2/3 牌：恢复 **2** 点生命
- 出 0 牌：施加 **3** 层中毒，格挡 **伤害的½（向上取整）**

**Stage 强化**：
- **Stage 2**：生命上限 +10（50）
- **Stage 3**：进攻 4/5/6/0 伤害 +1（变为 4/4/4/3）
- **Stage 4**：防御 1/2/3 恢复生命 +1（变为 3）

## Boss · 自由之鹰（CastleEagle）

**生命值**：35　　**手牌上限**：3  
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**被动**：Boss **进攻开始之前**，对玩家施加 **1** 层流血。

**飞翔（正面 buff）**：
- 上限 **2** 层
- 被攻击时花费 **1** 层尝试躲避伤害，成功率 **1/2**
- 失败后可再花费 1 层继续尝试
- 与守护用于同一次伤害时 **只能二选一**
- 只能躲避伤害，**不能**躲避本次攻击附带的 buff（道具闪避可以）
- 怪物持有飞翔时，受到攻击会优先尝试飞翔躲避，再考虑守护

**进攻**：
- 出 1/2/3 牌：造成 **4/5/6** 点伤害
- 出 4/5/6 牌：清除玩家所有正面 buff，造成 **3** 点 **不可防御** 伤害
- 出 0 牌：获得 **2** 层飞翔，造成 **4** 点伤害

**防御**：
- 出 1/2/3 牌：反击 **3** 点伤害
- 出 0 牌：**免疫所有伤害**

**Stage 强化**：
- **Stage 2**：生命上限 +10（45）
- **Stage 3**：所有伤害 +1
- **Stage 4**：反击伤害 +1

---

## Boss · 石像鬼（CastleGargoyle）

**生命值**：50　　**手牌上限**：3  
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**出现条件**：仅在 **Stage 2/3/4** 刷出

**进攻**：
- 出 1/2/3 牌：获得 **1** 层飞翔，造成 **3** 点伤害
- 出 4/5/6 牌：获得 **1** 层守护，造成 **3** 点不可防御伤害
- 出 0 牌：造成 **3** 点 **不可防御** 伤害，玩家 **随机丢失 1 个道具**，石像鬼 **抽取 1 张牌**

**防御**：
- 出 1/2/3 牌：格挡 **伤害的½（向上取整）**，施加流血。
- 出 0 牌：**免疫所有伤害**（不免疫 buff），**抽取 1 张牌**

**Stage 强化**：
- **Stage 3**：所有伤害 +1
- **Stage 4**：防御 1/2/3 牌额外恢复 **1** 点生命

Boss 房从本场景 Boss 池 **等可能** 刷新一只（隐之避役 / 自由之鹰 / 石像鬼）。
