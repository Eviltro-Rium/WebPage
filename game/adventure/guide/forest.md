# 丛林场景 · 怪物图鉴

所有怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

---

## 丛林猴（ForestMonkey）

**生命值**：18

**进攻**：
- 出 1/2/3 牌：造成 **4** 点伤害
- 出 4/5/6 牌：造成 **3** 点伤害，恢复 **3** 点生命

**防御**：
- 出 1 牌：恢复 1 点生命
- 出 2 牌：恢复 2 点生命
- 出 3 牌：恢复 3 点生命

**Stage 强化**：
- **Stage 2**：生命上限 +6（24）
- **Stage 3**：所有伤害 +1
- **Stage 4**：防御恢复 +1

---

## 丛林鹿（ForestDeer）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：造成 **3** 点伤害，获得 1 层【守护】
- 出 4/5/6 牌：造成 **5** 点伤害

**防御**：
- 出 1/2/3 牌：格挡至多 2 点伤害，获得 1 层【茂盛】
  - 【茂盛】：正面 buff，每有 1 层【茂盛】，进攻开始前恢复 1 点生命，上限 2 层

**Stage 强化**：
- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有伤害 +1
- **Stage 4**：格挡 +1

---

## 丛林鳄（ForestCrocodile）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：造成 **1 + 玩家【流血】层数 × 2** 点伤害
- 出 4/5/6 牌：造成 **2** 点不可防御伤害，施加 1 层【流血】


**防御**：
- 出 1/2/3 牌：格挡 1/2（向上取整）点伤害。

**Stage 强化**：
- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有伤害 +1
- **Stage 4**：防御额外施加 1 层【流血】

## 丛林熊猫（ForestPanda）· Boss

**生命值**：45　**手牌上限**：3  
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**进攻**：
- 出 1/2/3 牌：造成 **3** 点伤害，恢复 1 点生命
- 出 4/5/6 牌：造成 **2** 点不可防御伤害，获得 2 层【守护】
- 出 0 牌：获得【茂盛】和 1 层【守护】，造成 **5** 点伤害

**防御**：
- 出 1/2/3 牌：格挡 2 点伤害；当拥有 2 层【茂盛】时额外格挡 2 点
- 出 0 牌：免疫所有伤害和即将被施加的 debuff，清除自身所有 debuff

**Stage 强化**：
- **Stage 2**：生命上限 +10（55）
- **Stage 3**：进攻伤害 +1
- **Stage 4**：格挡 +1

## 蟒蛇（ForestPython）· Boss

**生命值**：35　**手牌上限**：3  
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**进攻**：
- 出 1/2/3 牌：造成 **1/2/3** 点伤害，抽取 1 张牌
- 出 4/5/6 牌：先施加 1 层【中毒】，造成 **2 × 玩家【中毒】层数** 点伤害
- 出 0 牌：先施加 1 层【中毒】，造成 **2 × 玩家【中毒】层数** 点不可防御伤害

**防御**：
- 出 1 牌：反击 1 点伤害
- 出 2 牌：反击 1 点伤害
- 出 3 牌：反击 2 点伤害
- 出 0 牌：与玩家均摊伤害（向上取整），不影响 buff 施加

**Stage 强化**：
- **Stage 2**：生命上限 +10（45）
- **Stage 3**：进攻伤害 +1
- **Stage 4**：防御反击 +1

---

## 树精（ForestDryad）· Boss（Stage 2/3/4）

**生命值**：50　**手牌上限**：3  
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**进攻**：
- 出 1/2/3 牌：获得 1 层【茂盛】，造成 **1/2/3** 点不可防御伤害
- 出 4/5/6 牌：造成 **4** 点伤害，将自身所有 debuff 转移给对手
- 出 0 牌：清除双方所有 buff，造成 **6** 点伤害

**防御**：
- 出 1/2/3 牌：格挡 1/2（向上取整）点伤害，获得 1 层【茂盛】
- 出 0 牌：免疫所有伤害和 debuff

**Stage 强化**：
- **Stage 2**：生命上限 +10（60）
- **Stage 3**：进攻伤害 +1
- **Stage 4**：格挡 +1

Boss 房从本场景 Boss 池 **等可能** 刷新一只（丛林熊猫 / 蟒蛇 / 树精）。
树精仅在 **Stage 2/3/4** 出现。

每一层场景随机等可能刷新。
