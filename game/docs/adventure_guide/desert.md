# 沙漠场景 · 怪物图鉴

场景框架已就位（地图 CSV、背景图、怪物池注册、掉落规则分组），怪物陆续填充中。

所有怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 沙暴蛮牛（DesertBison）

### 生命值：24

### 进攻：

- 出 1/2/3 牌：造成 **2 × [流血]层数🗡️**
- 出 4/5/6 牌：造成 **2🗡️**（不可防御），施加 1 层[流血]，获得 1 层[暴击]

### 防御：

- 出 1/2/3 牌：反击 **1/2/3🗡️**，施加 1 层[流血]

### Stage 强化：

- **Stage 2**：生命上限 +6（30）
- **Stage 3**：进攻 1/2/3 技能改为：造成 **3 × [流血]层数🗡️**
- **Stage 4**：防御技能施加[流血]层数 +1

### 掉落：投出1-3，掉落[流血]战利白卡；投出4，掉落[暴击]战利白卡

## BOSS·鳄神索贝克（DesertSobek）

### 生命值：35

### 被动[丰饶]（非独立 buff，不进 Buff 图鉴）：被击败时若持有至少 1 层[茂盛]，立即清除自身**所有正面 buff**（含[茂盛]），生命恢复至 **15**（复活，可多次）；无[茂盛]时正常被击败。

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，施加[流血]
- 出 4/5/6 牌：造成 **5🗡️**，该技能牌被指定为🟢，获得[茂盛]；🟡，获得[暴击]
- 出 0 牌：玩家和索贝克均获得[茂盛]，对手每有1层正面buff，造成 **3🗡️**，伤害<=3时变为不可防御。

### 防御：

- 出 1/2/3 牌：恢复 **3❤️**
- 出 0 牌：免疫所有伤害，若有[茂盛]，清除1层[茂盛]反击 **3🗡️**

### Stage 强化：

- **Stage 2**：生命上限 +7（42）
- **Stage 3**：所有进攻伤害 **+1**。
- **Stage 4**：防御恢复 **1❤️**


### 掉落：投出1-4，掉落[茂盛]战利白卡；5，掉落[暴击]战利白卡；6，掉落[流血]战利白卡

## BOSS·嘲风鬣狗（DesertHyena）

### 生命值：40

### 印记[嘲弄]：鬣狗**进入防御阶段**时获得嘲弄印记（图标 `items_icons/mock.webp`），投 12 面骰选色（1–3🔴 / 4–6🟡 / 7–9🔵 / 10–12🟢），以**卡片底色**标出本阶段失效的进攻颜色；该色进攻全空（无伤害、无附带效果），鬣狗也无需防御。鬣狗**进入进攻阶段**时清除印记；下次再进入防御阶段重新判定。

### 进攻：

- 出 1/2/3 牌：造成 **2+2\*[流血]层数🗡️**
- 出 4/5/6 牌：施加 1 层[流血]，获得[暴击]目标每有一张手牌，造成 **1🗡️**
- 出 0 牌：翻开玩家牌库顶 1🃏（判定后置入弃牌堆）。数字牌（含非 0）造成 **点数×1.5（向上取整）🗡️**；非数字牌或数字 0：不造成伤害，施加 2 层[流血]与[荆棘]，再抽 1🃏

### 防御：

- 出 1/2/3 牌：反击 **1/2（向上取整）点🗡️**
- 出 0 牌：反击 **6🗡️**，获得[暴击]，攻击方选择 1🃏弃掉
### Stage 强化：

- **Stage 2**：生命上限 +10（50）
- **Stage 3**：进攻技能牌被指定为🟡，自动变成不可防御（不消耗暴击）。
- **Stage 4**：防御恢复 **1❤️**

### 掉落：投出1-4，掉落[流血]战利白卡；5，掉落[暴击]战利白卡；6，掉落[荆棘]战利白卡

## 怪物池

- 怪物池与 Boss 池在 `adventure/js/monsters/desert.js` 中注册。
- 池为空时，引擎按全局已注册怪物兜底（`adventure_engine.js` 的 `_pickMonsterName` / `_pickBossName`）。
- 战利白卡掉落规则注册在 `adventure/js/engine/loot.js` 的 `SCENE_RULES.desert`。
