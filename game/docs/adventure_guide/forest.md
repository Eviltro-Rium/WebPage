# 丛林场景 · 怪物图鉴

普通怪物按 stage 逐级强化（累积叠加）；箭毒蛙、静河水豚、食人鱼仅在 Stage 3/4 精英房出现，不进入普通房或挑战房：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。


## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 藤噪顽猴（ForestMonkey）

### 生命值：18

### 进攻：

- 出 1/2/3 牌：造成 **4🗡️**
- 出 4/5/6 牌：造成 **3🗡️**，恢复 **3❤️**

### 防御：

- 出 1 牌：恢复 1❤️
- 出 2 牌：恢复 2❤️
- 出 3 牌：恢复 3❤️

### Stage 强化：

- **Stage 2**：生命上限 +6（24）
- **Stage 3**：所有伤害 +1
- **Stage 4**：防御恢复 +1

### 掉落：投出1-4，掉落[茂盛]战利白卡

## Boss · 缠枝巨蟒（ForestPython）

### 生命值：35

### 进攻：

- 出 1/2/3 牌：造成 **2🗡️**；当玩家有 **≥ 2 层[中毒]** 时，额外抽取 1🃏
- 出 4/5/6 牌：先施加 1 层[中毒]，再按 **[中毒]层数 × 3 🗡️**
- 出 0 牌：先施加 1 层[中毒]，再按 **[中毒]层数 × 3 🗡️**（满层最多 6🗡️；不可防御）

### 防御：

- 出 1/2/3 牌：反击 **1/2/3🗡️**，施加 1 层[中毒]
- 出 0 牌：与玩家均摊伤害（向上取整）🗡️，并施加 1 层[中毒]（不影响其他 buff 施加）

### Stage 强化：

- **Stage 2**：生命上限 +10（45）
- **Stage 3**：进攻 1/2/3/0 伤害 **+1**（4/5/6 倍率不变）
- **Stage 4**：防御额外恢复 1 ❤️

### 掉落：投出1-6，掉落[中毒]战利白卡

## 精英房

Stage 3/4 丛林的每张地图固定有 **2 个精英房**（编码 `8`），从上述三只精英怪中抽取。基础奖励、胜利恢复与兽元结算同普通房；每只精英独立投掷 **2 次**战利品骰。

## 精英通用掉落

击败精英池怪物时，每次投掷除下表外仍适用各怪原有面数区间；**投出 11、12 与上表相同**。

- 投出 **10**：掉落 [双抽]战利白卡（`DrawTwoTrophy`，双源；图标同白卡 +3）
