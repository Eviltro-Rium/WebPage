# 冒险模式 · 房间类型

地图单元格类型、CSV 编码、进门流程与探索规则。实现见 `adventure/js/content/room.js`、`adventure/js/engine/adventure_engine.js`；地图 CSV 在 `adventure/maps/`。

**奖励结算**见本文下半部分「奖励结算」。**商店 / 铁匠经济**见 [accessories.md](accessories.md)、[consumables.md](consumables.md)。**战利掉落**见 [loot.md](loot.md)。

## CSV 编码（现行）

| 码 | `RoomType` | 中文 | 战斗 | 简述 |
|----|------------|------|------|------|
| **-1** | `empty` | 空 | — | 地图外，不可进入 |
| **0** | `start` | 起点 | 无 | 初始位置，安全 |
| **1** | `normal` | 普通 | 1v1 | 打怪 → 基础奖励 + 兽元结算 |
| **2** | `boss` | Boss | 1v1 Boss | 通关本层；掉落见 loot |
| **3** | `item` | 奖励 | 无 | 支路；兽元开门后领本层奖励 |
| **4** | `shop` | 商店 | 无 | 金币买道具 / 配饰 / 兽元 |
| **5** | `blacksmith` | 铁匠铺 | 无 | 支路；金币开门后用兽元锻配饰 / 锻造白卡 |
| **6** | `challenge` | 挑战 | 1v2 | 挑战奖励 + 兽元全选 |
| **7** | `glitch` | 故障 | 随机 | 一次 D12 事件，可先离开后再投 |

放置约定（现行）：

- **奖励房（3）**、**铁匠铺（5）** 放在**支路**，不放在起点→Boss 最短路径上。
- 奖励房进门消耗 **2** 个随机普通兽元（万能可替代）；开门后本层只 roll **一次**奖励；未领可 `stashedLoot` 再进领取。
- 探索边界：起点始终可扩；战斗房需 **cleared**；奖励/铁匠需 **doorUnlocked**；商店需实际进入过（有货槽）。
- 故障房实际进入即打开邻格探索；尚未投骰时离开不消耗事件机会。

## 现行房间说明

### 起点（`start` · 0）

- 玩家出生点；无战斗、无奖励挂起。
- 始终打开探索邻格。

### 普通房（`normal` · 1）

- 进入 → 与当前场景池怪物 **1v1** → 胜利回复 **3**❤️ → 基础奖励（可留房）→ 专属兽元结算（每房一次）。
- 详见 下方「奖励结算 · 普通房」。

### 挑战房（`challenge` · 6）

- 进入 → **1v2** → 击败第一只时回 3❤️ 并补牌；击败第二只结束时**不回血、不补牌**。
- 挑战房奖励**不可**暂存；另有挑战兽元结算。
- 详见 下方「奖励结算 · 挑战房」。

### Boss 房（`boss` · 2）

- 本层终点；胜利后战利 D12 **独立投 3 次**（成功即入手，不可暂存）；**本房不回血**，进入下一 stage 时回 **10**❤️。
- 详见 下方「奖励结算 · Boss 房」 与 [loot.md](loot.md)。

### 奖励房（`item` · 3）

- 无战斗；开门兽元 → 本层奖励池（可留房）。
- 详见 下方「奖励结算 · 奖励房」。

### 商店（`shop` · 4）

- 无战斗；金币购买。槽位与刷新见 [consumables.md](consumables.md) / [accessories.md](accessories.md)。
- 优惠券配饰使商品价 ×½（刷新费不打折）。

### 铁匠铺（`blacksmith` · 5）

- 无战斗；进门费（按层 1–4 金）后，用兽元兑换配饰 + **1** 锻造白卡槽。
- 锻造池 = `trophyKind` 为 **`forge` ∪ `both`**；掉落白卡不进此槽。刷新选中槽 **2** 金。
- 详见 [accessories.md · 铁匠铺](accessories.md#铁匠铺)。

### 故障房（`glitch` · 7）

- 进入后，玩家可以选择，抽取一个事件（投12面骰），也可以选择直接离开，无论怎样房间标记已探索。
- 投出 **1-2** ：随机抽取一个其他场景同stage的怪物进行战斗，正常结算掉落但无奖励结算。可以用[回溯沙漏]逃逸，返回后无法再抽取事件。
- 投出 **3-4** ：玩家选择一个道具丢弃。
- 投出 **5-6** ：清除玩家所有buff。
- 投出 **7-8** ：玩家将所有手牌放入弃牌库，重新抽取 3 张牌。
- 投出 **9-10** ：恢复10❤️，补齐手牌。
- 投出 **11-12** ：获得随机一次性道具。
- 一个房间只能触发一次事件，不抽取事件，直接退出故障房以后，可以返回房间再抽取。不能使用遥控骰子改变事件，但是可以使用“魔术师”。stage1-2，只含 1 个故障房；stage3-4，含 2 个故障房。
- 魔术师沿用现行规则：非致盲且生命大于3时，可消耗3点生命调整骰面±1，每次事件仅一次；骰面范围1–12。确认骰面后执行事件。
- 道具丢弃只针对一次性道具；没有道具则直接结束。获得道具超出6槽时，先选择舍弃多余道具。
- 异场景战斗只结算战利品，不发普通房胜利回复、基础奖励或兽元；战斗胜利配饰照常在返回地图时触发。
- 骰面、魔术师调整、事件处理与遭遇怪物均保存；刷新不会重投。全部60张场景地图按层数替换普通房，已有存档保留原地图。

## 规划中的新房间（未落库 · 草案）

优先：**无战斗决策房**（奇遇/祭坛、岔路赌约）→ 精英 → 赌坊。引擎接 CSV 码 + 进门挂起即可；UI 图例分色见群聊约定。

| 码（草案） | `RoomType`（草案） | 中文 | 战斗 | 一句话 |
|------------|-------------------|------|------|--------|
| **12** | `event` | 奇遇 / 祭坛 | 无 | 进门一次事件卡（献祭/交换/自伤换 buff 等）；与铁匠错开（这里=赌或献，铁匠=买） |
| **8** | `fork` | 岔路赌约 | 无 | 二选一或三选一（多金 / 多兽元 / 少伤通行等），只弹一次 |
| **9** | `elite` | 精英 | 1v1 强化 | 单怪加压（多层被动或更高伤）；奖励介于普通与挑战之间 |
| **10** | `rest` | 休息营 | 无 | 回血 + 整理手牌；**本层限进 1 次**（可带轻度风险变体） |
| **11** | `gambling` | 赌坊 | 无 | 强制 D12（可吃遥控/魔术师）；押兽元或消耗品赌掉落白卡 |

### 奇遇 / 祭坛（`event` · 12）

- **支路**；无战斗。
- 进门挂起事件选项（复用选择卡 / 弃牌拣选器）。
- 示例选项（未定稿）：弃 1 张手牌 → 随机兽元；自伤 3❤️ → 1 张双源白卡；献 1 普通兽元 → 清除 1 负面。
- 本房是否可重复进入、是否 `cleared` 后封事件：待定（建议 **一次事件后标记 cleared**）。

### 岔路赌约（`fork` · 8）

- **支路**；无战斗。
- 仅一次三选一（或二选一），选完即结算并打开探索。
- 地图图标建议分叉；不 roll 战斗怪。

### 精英房（`elite` · 9）

- **Stage 3–4** 地图引入（编码 `9`）；1–2 层不出现精英房格子。
- 1v1，从场景精英池刷新怪物（城堡测试：钟楼蝠 / 夜巡幽魂 / 盗宝哥布林）。
- 奖励结算与普通房相同（+3 战斗恢复、基础奖励、兽元）；战利品骰**投 2 次**。
- UI：紫框，图标 `elite_room.png`。

### 休息营（`rest` · 10）

- 回血（建议 **5**❤️ 或至上限一半，待定）+ 可选整理手牌（弃牌再抽，次数待定）。
- **每层最多进入 1 次**（引擎用 stage 计数）。
- 风险变体（可选）：小概率遇小怪或丢失 1 消耗品——需明确 UI 风险提示。

### 赌坊（`gambling` · 11）

- 复用 D12 + `pendingDiceControl`（遥控 → 魔术师）。
- 押注与赔率待定；失败扣押注，成功给掉落白卡或双源。
- 第三波再做。

### 地图放置建议（草案）

- 后期减少纯 `normal` 密度：部分改为 `elite`，支路插入 `event` / `fork`。
- `rest` 每层至多 1 格；`gambling` 稀有支路。
- 奖励房 / 铁匠铺放置规则不变。

## 奖励结算

按当前实现（`adventure_engine.js`、`currency.js`）整理。原 `rewards.md` 已并入本文。

### 通用规则

#### 战斗胜利回复

| 房间类型 | 胜利后回复生命 |
|----------|----------------|
| 普通房 | **3** HP（不超过上限）；Serenity 不获得此项「战斗恢复」 |
| 挑战房 | 击败**第一个**敌人时（战斗内）回复 **3** HP 并补一次牌；击败第二个敌人结束战斗时**不回复、不补牌** |
| Boss 房 | 不回复；改为**进入下一个 stage 时**回复 **10** HP（不超过上限，地图界面播放特效与飘字；同一层重新载入不重复） |

生命核心（LifeCore）在战斗胜利后的首次返回地图时结算，每件恢复 3 点生命；配饰图标闪烁、血条发光，并显示实际回血飘字。领取奖励期间不提前回复，待触发效果随存档保存，只结算一次。直接前往下一 Stage 时，生命核心与新层 10 点回血在新地图依次结算。

#### 道具与兽元上限

- **一次性道具槽**：最多 **6** 格；领取含道具的奖励时先完整加入，超过 6 个后强制选择舍弃多余道具。
- **兽元上限**：默认 **8**；持有「兽元袋」配饰时为 **12**。超出上限须先舍弃，再继续结算。
- **万能兽元**：可替代任意普通兽元支付开门、铁匠铺等费用。
- **支付抉择弹窗**（铁匠铺战利/配饰兑换、奖励房开门等）：
  - 引擎挂起 `pendingBeastPayment`（含 `plans`）；玩家 `confirmBeastPayment` / `cancelBeastPayment`
  - 方案字段 `usesWild` = 该方案是否用万能**顶替普通兽元**（成本里写死的万能不算顶替）
  - 弹窗条件：`plans.length > 1`，或任一方案 `usesWild`（覆盖「只能用万能顶」与「可用可不用万能」）
  - 弹窗内各方案用**兽元图标**展示扣款组合（`currency.js` 的 `BEAST_ICON`），不用「本/草/水/火/万」等文字标签；含顶替时也用万能图标区分，不用「（含万能）」文案
  - `listBeastPaymentPlans` 按扣款组合（各类型数量 + 万能数量）**去重**；**不按**顶替颗数（`wildSub`）再合并（已锁定，勿再改回合并）
    - 例：需本+火、袋 `{ben:1,huo:1,wuneng:2}` → 4 条：万×2 / 火+万 / 本+万 / 本+火（`usesWild:false`）；`wuneng:1` → 3 条
    - 弹窗直接吃引擎 `plans`（几条画几条）；万×2 只画万能图标加 `×2`；UI 渲染前可再按 spend 去重；缓存 `beast-pay-combos`
  - 唯一方案且无顶替（`!usesWild`）→ **直接扣**；成本写死的万能仍照常预留并扣除

#### 「留在房间」

部分奖励可选择不立即领取，存入当前房间的 `stashedLoot`，之后再次进入该房间时可领取：

| 房间类型 | 可暂存内容 |
|----------|------------|
| 普通房 | 战斗**基础奖励**（不含专属兽元结算） |
| Boss 房 | **不可**暂存；战利品骰成功掉落后立即入手 |
| 挑战房 | **不可**暂存挑战房奖励（仅「领取」） |
| 奖励房 | 留在房间的待领奖励（若有） |

地图上已清除的房间若仍有 `stashedLoot`，格子上会显示待领标记。

#### 随机道具 / 配饰池

- **道具掉落**：在全部**一次性道具**中等概率抽取（不含配饰）。
- **配饰掉落**：在全部**配饰**中等概率抽取。
- 若配饰池为空而 roll 到配饰，会改为给予备用金币（挑战房 **6** 金）。

### 普通房

**流程**：进入 → 与 1 名怪物对战 → 胜利 → **基础奖励** → **专属兽元结算** → 返回地图。

#### 1. 基础奖励（`_rollBasicCombatReward`）

战斗胜利后先滚动一次，权重合计 **12**：

| 结果 | 权重 | 概率 |
|------|------|------|
| 流浪商人（出售 1 个随机配饰） | 1 | 1/12 |
| **5** 金币 | 1 | 1/12 |
| **6** 金币 | 1 | 1/12 |
| **7** 金币 | 1 | 1/12 |
| **8** 金币 | 1 | 1/12 |
| **9** 金币 | 1 | 1/12 |
| **10** 金币 | 1 | 1/12 |
| 随机道具 ×1 | 3 | 3/12 |
| 随机道具 ×2 | 2 | 2/12 |

> **流浪商人**：`basic = { kind: 'merchant', accessory, price, sold }`，从随机配饰池出 1 个（已达上限的不出；池空才退回无奖励）。售价同商店配饰 **15 金**，优惠券减半。购买 `eng.buyMerchantAccessory()`，成功返回 `{ ok: true, price }`，失败返回 `reason`（`gold` / `sold` / 互斥或上限）+ `message`（UI 直接显示）；快照 `price` 已含优惠券折扣；事件 `buy` / `buyFail`（`source: 'merchant'`）。「不买，继续」走 `claimCombatReward()` 直接进兽元结算；暂缓离开时未售商品留在房间。

- 「不买，继续」和「留在房间」均保留未售商品；离开、重进或刷新后，仍可与同一位商人交易，不会重新抽取商品。
- 商人房间在地图上显示流浪商人图标；购买成功后商品与标识一并清除，不补货。图标为 `icons/adventure_ui_icons/wandering_merchant.webp`（64×64、透明背景）。
- 回房交易页实时显示优惠券后的价格、金币与携带上限限制；返回交易不会再次结算兽元奖励。

可**领取**或**留在房间**。领取后进入下一步兽元结算。

#### 2. 专属兽元结算（`AdventureCurrency.rollBeastReward`）

基础奖励处理完毕后，每个普通房**额外**进行一次兽元结算（每房仅一次，以 `beastTokenClaimed` 标记）。8 种情况等概率（各 **1/8**）：

| 情况 | 概率 | 内容 | 玩家操作 |
|------|------|------|----------|
| 0 | 1/8 | 本 / 草 / 水 / 火 各 ×1 | 从中选 **2** 个 |
| 1–6 | 6/8 | 两种普通兽元各 ×2（共 4 个槽位） | 从中选 **2** 个 |
| 7 | 1/8 | 万能兽元 ×1 | 自动获得，点领取即可 |

情况 1–6 的两种兽元组合为固定 6 对：本+草、本+水、本+火、草+水、草+火、水+火。同类型若出现两个槽位，可各选一次（例如选到 2 个本兽元）。

### 挑战房

**流程**：进入 → **1v2** 对战 → 胜利 → **挑战房奖励** → **挑战房兽元结算** → 返回地图。

- **没有**普通房的「基础奖励」池。
- 挑战房奖励**只能领取**，不能留在房间。

#### 1. 挑战房奖励（`_rollChallengeBonusReward`）

权重合计 **12**：

| 结果 | 权重 | 概率 |
|------|------|------|
| 6 金币 | 1 | 1/12 |
| 12 金币 | 2 | 2/12 |
| 配饰 ×1 | 2 | 2/12 |
| 道具 ×2 | 4 | 4/12 |
| 道具 ×3 | 3 | 3/12 |

#### 2. 挑战房兽元结算

领取挑战房奖励后触发，每房仅一次：

| 概率 | 内容 | 玩家操作 |
|------|------|----------|
| **12.5%**（1/8） | 万能兽元 ×**2** | 自动获得，点领取 |
| **75%** (6/8) | 随机两种普通兽元各 ×2 | 自动获得，点领取 |
| **12.5%**（1/8） | 本 / 草 / 水 / 火 各 ×1 | 自动获得，点领取  |

### 奖励房

**流程**：支付开门兽元 → 进入 → **本层只滚动一次**奖励 → 领取或留在房间。

- **无需战斗**。
- 通常位于支路，不在起点 → Boss 的最短路径上。
- **不可刷奖**：本层领取后再次进入不会重新滚动；留在房间时再次进入仍是同一份待领奖励。

#### 开门费用

首次进入须支付 **2 个普通兽元**（类型在进图时随机，可相同；**不含**万能作为需求类型，但可用万能**替代**不足的部分）。开门后 `doorUnlocked` 永久为真，同层不再收费。

#### 本层奖励（`_rollBonusRoomReward`）

本层**首次**进入且尚无待领/未领取时滚动一次，并立刻写入 `stashedLoot` 锁定内容。之后：

- 有 `stashedLoot` → 展示同一份待领奖励
- 已 `rewardClaimed` → 不再滚动，直接返回地图

权重合计 **12**：

| 结果 | 权重 | 概率 |
|------|------|------|
| 6 金币 | 1 | 1/12 |
| 12 金币 | 2 | 2/12 |
| 配饰 ×1 | 2 | 2/12 |
| 道具 ×2 | 4 | 4/12 |
| 道具 ×3 | 3 | 3/12 |

可**领取**或**留在房间**。领取成功后本层不可再获得奖励房奖励。

### Boss 房

**Stage 1–3 流程**：进入 → 与 Boss 对战 → 击败 Boss → **连续投 3 次战利品骰**（成功掉落立即入手）→ 返回地图 / 进入下一层。

每次独立投掷 D12，按该 Boss 原有的掉落表判定，可获得对应战利白卡，也可能无收获；不同次可以重复获得同名白卡。三次投掷替代原来的单次掉落与随机配饰奖励，**总共 3 次，不额外投第 4 次**。成功掉落的白卡自动加入手牌与战利白卡背包，并播放获取动画；不可留在房间。

每个 Stage 从本局未探索且在该层有可用 Boss 的场景中等概率抽取：城堡、丛林、冻洋、沙漠。四个场景从 Stage 1 均可抽取；沙漠第一层的 Boss 为鬣狗或索贝克，法老从 Stage 2 起加入。一局四个 Stage 的场景不重复，每层仍随机选择对应的 3 个地图版本之一。已探索场景随存档保存，刷新后继续排除；旧存档没有场景历史时，从当前场景开始记录。

**Stage 4 流程**：击败本层 Boss → 完成 **3 次战利品骰**及掉落动画 → 宣布冒险胜利 → 点击“返回游戏主页”。不再生成下一层，也不循环回 Stage 1。最终胜利会作为通关检查点保存，刷新后恢复胜利弹窗；返回游戏主页时清除冒险和战斗存档。

#### 与普通房的差异

| 项目 | Boss 房 | 普通房 |
|------|---------|--------|
| 回复生命 | 进入下一 Stage 的地图时 **10** HP；战胜 Boss 时不回复 | 胜利后 3 HP（Serenity 除外） |
| 战斗奖励 | **自身 D12 掉落表独立投 3 次**（可无收获） | 基础奖励池 |
| 专属兽元结算 | **无** | 有（8 种情况） |
| 通关 | Stage 1–3 结算后可选**进入下一层**；Stage 4 完成掉落后冒险胜利 | — |
| 留在房间 | 不支持（白卡自动入手） | 支持（基础奖励） |

Stage 1–3 完成三次掉落后，结算弹窗提供「返回地图」与「进入下一层」，不再提供配饰领取或暂存选项。

再次进入已战胜的 Boss 房时，不会重新投掷战利品骰；Stage 1–3 可选择进入下一层地图。
