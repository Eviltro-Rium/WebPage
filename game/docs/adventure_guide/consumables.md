# 冒险模式 · 一次性道具图鉴

一次性道具放入 **6 格道具槽**，使用后消耗。来源包括：战斗胜利掉落、商店购买。

奖励领取时不会因为道具槽已满而被拒绝：奖励会先完整加入道具槽，超过 6 个后立即进入舍弃流程，玩家选择要保留的道具。

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 使用规则概览

| 使用场景 `useScene` | 含义 |
|---------------------|------|
| `both` | 地图界面与对战界面均可使用 |
| `combat` | 仅对战界面可用 |
| `map` | 仅地图界面可用（当前无此类道具） |

对战中：

- 玩家**只能在可以选择出牌的时候**使用道具：
  - **进攻**：`PLAYER_PLAY` 选牌出牌期间（选色弹窗期间除外）；攻击修正在**伤害确认后**弹出，不在出牌瞬间询问。
  - **防御**：NPC 出牌后进入 `PLAYER_DEFEND`、选择防御牌期间；不可防御时在跳过窗口也可使用。
  - 动画中、NPC 回合、弃牌/技能子阶段等其他时刻不可使用。
- **攻击修正**类不在道具槽直接点用；当本次进攻已确认会造成数值伤害时弹出（含判定/追加牌结算完成后），选择是否消耗。**垃圾回收**在无数值伤害时也可弹出（仍须完成技能结算流程）。
- **闪避**仅可在防御出牌阶段点用；使用后本次 NPC 攻击作废（伤害与本轮攻击附带负面均取消）。

## 进攻修正

出牌进攻且已确认会造成数值伤害时，若持有攻击修正道具会询问是否使用（需判定的技能会等判定/追加确认完成后再问）。选择后道具消耗，并为本次进攻附加额外数值伤害。**垃圾回收**在无数值伤害的进攻技能结算前也会询问（与其他攻击修正共用一次选择）。

| 显示名 | 内部名 | 价格 | 效果 |
|--------|--------|------|------|
| 攻击修正Ⅰ | `AttackMod1` | 1 | 数值伤害 +1 |
| 攻击修正Ⅱ | `AttackMod2` | 2 | 数值伤害 +2 |
| 攻击修正Ⅲ | `AttackMod3` | 3 | 数值伤害 +3 |
| 破防之矛 | `ArmorBreakSpear` | 3 | 变为不可防御 |
| 邪恶赌盘 | `EvilRoulette` | 5 | 投 D12：1–8 翻倍；9–12 归零并跳过防御 |
| 垃圾回收 | `GarbageRecycle` | 6 | 技能结算完成后收回本次打出的进攻牌 |

- **场景**：仅对战
- **限制**：加伤/破防/赌盘仅对「有数值伤害」的进攻生效；**垃圾回收**可在无数值伤害时使用；不能在防御阶段从道具槽直接使用
- **破防之矛**：仅当本次进攻**原本可防御**时出现；与攻击修正Ⅰ/Ⅱ/Ⅲ、邪恶赌盘共用道具栏选择，**同一技能只能选用一种**修正；选用后不能再触发[暴击]破防
- **邪恶赌盘**：与攻击修正Ⅰ/Ⅱ/Ⅲ、破防之矛共用选择；投出 1–8 时将已确认伤害翻倍，投出 9–12 时伤害降为 0 并跳过防御
- **垃圾回收**：与上述攻击修正共用选择；在整次进攻（含防御与伤害结算）完成后，将本次打出的进攻牌收回手牌，弃牌库顶恢复为出该进攻牌之前的牌和颜色。防御牌仍留在怪物弃牌堆；玩家与怪物牌堆互不混洗（暂借/道具进攻牌不可收回）。
- [暴击]在攻击修正/破防选择**之后**再弹出；伤害需 >4（含加伤/翻倍后）

## 手牌操作

### 水晶球（`CrystalBall`）

- **价格**：6 金币
- **场景**：地图 + 对战
- **效果**：查看自己牌库顶 **3** 张牌并调整顺序放回，然后 **抽取 1 张牌**

- **交互**：排序弹窗**不得**提供「取消」或点遮罩关闭；只能「重置」或「确认放回」。
- **防白嫖**：地图首次预览即 `consumeNow` 消耗道具；战斗若走 cancel，引擎按原序确认并照常消耗（不能反复偷看不扣道具）。缓存可对齐 `crystal-oneshot`。

### 混沌球（`ChaosOrb`）

- **价格**：6 金币
- **场景**：仅对战
- **图标**：`icons/items_icons/chaos_orb.webp`
- **效果**：查看 **NPC 牌库顶 3 张牌**（不足则全部展示）。不可调整顺序；对每张牌选择：
  1. **放回牌库**（保持原相对顺序，左侧仍为牌库顶）
  2. **进入 NPC 弃牌堆**
- **限制**：仅可在玩家选牌出牌 / 选牌防御（含不可防御跳过）窗口使用；NPC 牌库为空时不可使用

### 卡牌大师（`CardMaster`）

- **场景**：地图 + 对战
- **效果**：使用时二选一：

  2. **弃掉全部手牌**，再从牌库抽取与弃牌前相同数量的牌
- **对战限制**：仅可在玩家选牌出牌 / 选牌防御（含不可防御跳过）窗口使用

### 弃牌符（`CardTalisman`）

- **价格**：3 金币
- **场景**：地图 + 对战
- **图标**：`icons/items_icons/card_talisman.webp`
- **效果**：选择弃掉 **1** 张手牌，然后抽取 **2** 张牌
- **限制**：手牌为空时不可使用；对战中仅可在玩家选牌出牌 / 选牌防御（含不可防御跳过）窗口使用
- **交互**：无 index 时引擎 `beginHandDiscard`（`kind: discardTalisman`）；UI 吃 `pendingHandDiscard`，见 `docs/small_rules.md`

### 熔炉（`Furnace`）

- **价格**：7 金币
- **场景**：地图 + 对战
- **图标**：`icons/items_icons/furnace.webp`
- **效果**：弃掉 **1** 张普通颜色手牌（红/黄/蓝/绿点数牌，不含黑白与道具牌），按颜色获得对应战利白卡并加入手牌：

  - 蓝 → 潜水战利白卡（`DivingTrophy`）
  - 绿 → 茂盛战利白卡（`LushTrophy`）
- **限制**：没有可熔炼的颜色牌时不可使用；对战中仅可在玩家选牌出牌 / 选牌防御（含不可防御跳过）窗口使用
- **交互**：无 index 时引擎 `beginHandDiscard`（`kind: furnace`, `filter: 'colorNumber'`）；UI 吃 `pendingHandDiscard`

## 防御闪避

### 闪避（`Dodge`）

- **价格**：7 金币
- **场景**：仅对战
- **效果**：在防御出牌阶段使用，**闪避本次 NPC 攻击并使其作废**（不结算伤害，并撤销本轮攻击附带的负面状态）
- **限制**：仅 `PLAYER_DEFEND`（含不可防御跳过窗口）可用；进攻阶段不可用
- **与飞翔区别**：闪避会取消即将施加的 buff；飞翔只能躲避伤害，不能躲避 buff

### 回溯沙漏（`RewindHourglass`）

- **价格**：8 金币
- **场景**：仅对战
- **效果**：立即退出当前战斗房间，手牌补至上限；本房间遭遇重置（不清空、不发奖励），下次进入时重新抽取怪物。故障房可逃逸，但已触发的事件不重置，返回后不能再次抽取
- **说明**：战斗中的生命与牌库变更会带回地图；本道具使用后消耗
- **测试模式**：直接结束本次测试并回到结果页（不重置房间）

## 捆缚（`Bind`）

- **价格**：8 金币
- **场景**：仅对战（进攻回合）
- **效果**：仅给当前对手施加捆缚标记。轮到该角色进攻时，双方正常补牌，**跳过该角色一次进攻**，转为玩家再进行一次进攻，同时清除该角色的标记。挑战房不会给另一只怪物加标记，也不会跳过未被捆缚的怪物。
- **使用限制**：
  - 只能在 `PLAYER_PLAY` 阶段使用
  - 每个进攻回合限用 **1** 次
  - 使用后道具栏上的其他捆缚暂时封锁（本回合不可再使用）
- **捆缚印记**：捆缚属于不可净化的印记，不会被净化牌或超级净化清除；只在被捆缚角色身上显示，成功跳过其进攻时自然移除。若该角色已被击败，标记不会转移给存活对手。
- **叠加**：额外进攻阶段中可再次使用捆缚（如有剩余），形成连续跳过

配饰图鉴见 [accessories.md](./accessories.md)。

## 战利白卡

战利白卡是可重复获得的特殊白色道具，不占普通道具槽。获得后立即加入玩家手牌，并登记到地图侧栏「战利白卡背包」。战斗掉落时播放飞入手牌动画；地图获取时播放飞入背包图标动画。

- 打出时按普通白牌规则自动指定当前颜色；可在任意弃牌库顶打出并继续搭桥（**零技能战利白卡**例外：不抽牌、不搭桥）。
- 打出后放入玩家弃牌库并额外抽 1 张牌；零技能、绿魔法和紫魔法不抽牌，双抽白卡抽 2 张。洗回后可再抽到。
- 背包无数量上限；可查看并丢弃。
- 标价多为 5 金币，**商店不出售**。
- **细分类**（按卡面图标来源；图标已从 `items_icons` 迁出的以现行路径为准）：
  - **掉落白卡**：图标来自 `buff_icons`。主要来自怪物 D12 掉落；**不可**铁匠锻造。定稿 **drop-only**（其余 buff 战利）。
  - **锻造白卡（仅锻造）**：主要图标来自 `card_icons`（**定时炸弹**暂留 `buff_icons`）。只进铁匠池、**不进**怪物掉落：俄盘 / 缴械 / **暴乱** / **定时炸弹**。
  - **双源白卡**：小药剂 / 净化之水 / 零技能 / 双抽 —— **掉落与铁匠均可获得**（铁匠池按可锻收录；也可写进怪物掉落表）。小药剂/净化图标暂留 `buff_icons`，零技能与双抽为 `card_icons`（双抽图标同白卡 +3）。
- **定稿字段**：`trophyKind: 'drop' | 'forge' | 'both'`（铁匠槽 = `forge` ∪ `both`；掉落表可含 `drop` ∪ `both`）。铁匠进店随机 1 槽，选中后 **2** 金币刷新。

### 掉落白卡（`buff_icons` · 不可锻造）

- **灼伤**（`BurnTrophy`）：对当前对手施加 1 层[灼伤]。
- **流血**（`PiercingTrophy`）：对当前对手施加 1 层[流血]。
- **冰冻**（`FreezeTrophy`）：使当前对手进入[冷冻]。
- **冰封**（`IceSealTrophy`）：对当前对手施加[冰封]。
- **失温**（`HypothermiaTrophy`）：对当前对手施加 1 层[失温]。
- **飞翔**（`FlyTrophy`）：获得 1 层[飞翔]。

### 遥控骰子（`DiceController`）

- **价格**：4金币；一次性道具，使用后消耗1个。
- **时机**：持有道具时，每次12面骰判定掷出结果后、效果结算前暂停。
- **操作**：掷骰后显示全宽底部卡片，选择「保留结果」不消耗道具；直接选择1–12的任一骰面则消耗1个遥控骰子。判定区保留骰面供参考。
- 可修改玩家或敌方的飞翔、沙盲、赌盘、怪物防御和战利品掉落等D12结果；不影响抽牌判定、6面骰等其他随机机制。
- **与魔术师配饰互斥**：不能同时持有/生效；若同次判定两者都曾可用，**先遥控再魔术师**（见 [accessories.md](accessories.md)「魔术师」）。
- 保留结果不消耗；指定骰面消耗1个。同一次判定不能重复使用；致盲时不可使用。
- 等待选择期间不允许出牌或结束回合；刷新后保留原结果和待选择状态，不重新掷骰。
- **手感**：引擎 `diceRoll.awaitControl = true`；有 pending 时 D12 翻滚约 240ms（`fast`）、投后等待 40ms，动画一开始即可开选面面板。 缓存可对齐 `dice-fast`。
