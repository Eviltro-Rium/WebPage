## Final Enemy · CorruptedRyan

### 生命值：50

### 被动：手牌上限为3，对手使用黑牌时，自己恢复2❤️

### 进攻：

- 出 1/2/3 牌：4🗡️，弃掉手中数字最小的非0🃏，然后再抽1🃏。（没有手牌则跳过）
- 出 4/5/6 牌：4🗡️，该技能牌为🔴获得[熔脉]；🟡获得[暴击]；🔵获得[潜水]；🟢获得[茂盛]
- 出 7 牌：造成剩余手牌 **数字之和点🗡️**，没有手牌则抽1🃏。
- 出 0 牌：清除自身所有debuff，抽2牌，造成 **数字之和点🗡️**。（魔法牌视作0点）

### 防御：

- 出 1/2/3 牌：反击2🗡️，恢复2❤️。
- 出 0 牌：免疫所有伤害和 debuff，施加[催眠]

### 最终战入口

击败 Stage 4 原本的场景 Boss，并完成三次战利品骰及掉落结算后，结算界面的「进入下一层」替换为「唤醒堕落 Ryan」。选择后在原 Boss 房开始最终战；击败堕落 Ryan 后才宣布冒险胜利。

也可先返回地图，再回到已清除的 Boss 房唤醒。唤醒不切换场景、不增加层数，也不触发跨层恢复。唤醒状态及最终战进度保存，刷新后继续最终战；旧版本已经通关的存档仍保留通关状态。

### 牌组与判定细节

- 使用统一的 23 张怪物牌组，手牌上限 3；白牌继承当前有效颜色，4/5/6 技能按有效颜色获得对应增益。
- 1/2/3 技能只弃掉剩余手牌中点数最小的非 0 数字牌，再抽 1 张。没有可弃数字牌时跳过换牌，仍造成 4 点伤害。
- 7 技能计算出牌后剩余手牌的数字之和；魔法牌不贡献点数。无剩余手牌时抽 1 张，不造成伤害。
- 0 技能计算本次抽到的两张牌的数字之和，不包含原有手牌，魔法牌按 0 点。抽到的牌留在手牌区。
- 防御 0 免疫本次攻击的伤害与附带负面状态，不清除此前已存在的负面状态。
