# 冻洋场景 · 怪物图鉴

所有怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 冻洋猞猁（FrozenOceanLynx）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：造成 **3🗡️**，施加[冷冻]
- 出 4/5/6 牌：造成 **4🗡️**，施加[冰封]

**防御**：
- 出 1/2/3 牌：防御**2🛡️**；若对手有[冷冻]，再反击 **2🗡️**

**Stage 强化**：
- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有伤害 +1
- **Stage 4**：格挡与反击各 +1

### 掉落：投出1-2，掉落冰冻战利白卡；投出3-4，掉落冰封战利白卡

## 冻洋蓝鲸（FrozenWhale）

**生命值**：25

**被动**：拥有[潜水]时免疫蓝色攻击的伤害，不阻止 buff 施加。

**潜水（正面 buff）**：
- 上限 **1** 层
- 持续 buff
- 免疫有效颜色为蓝色（含白色指定为蓝色）的攻击造成的伤害，但不阻止随附的 buff 施加
- 对手依旧可以对自己施加正面增益

**进攻**：
- 出 1/2/3 牌：造成 **2🗡️**，获得 **1** 层[潜水]
- 出 4/5/6 牌：对场上所有其他角色（包括 NPC 队友）造成 **4🗡️**（不可防御）；**防御阶段结束后**对对手施加 **1** 层[失温]

**防御**：
- 出 1/2/3 牌：反击 **2🗡️**，获得 **1** 层守护

**Stage 强化**：
- **Stage 2**：生命上限 +5（30）
- **Stage 3**：所有进攻伤害 +1

### 掉落：投出1-4，掉落潜水战利白卡

**Stage 强化**：

- **Stage 4**：防御时额外防御**2🛡️**

### 掉落：投出1-4，掉落流血战利白卡

## 冻洋海豹（FrozenOceanSeal）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：从牌堆抽 1 张牌展示，造成对应数字的**伤害**（数字牌放入弃牌堆；魔法牌加入手牌）
- 出 4/5/6 牌：造成 **4🗡️**，施加[致盲]

**防御**：
- 出 1/2 牌：格挡 **½🗡️**（向上取整）
- 出 3 牌：反击**相同点伤害**（守护/飞翔结算前的点数）

**Stage 强化**：
- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有进攻额外施加[冷冻]
- **Stage 4**：防御 3 额外**免疫所有伤害**（仍反击相同点伤害）

### 掉落：投出1-4，掉落缴械战利白卡

## 克拉肯（FrozenKraken）· Boss（Stage 2 起）

**生命值**：50　**手牌上限**：3 张
**牌库**：普通 NPC 牌库 + **2 张白色 0**

**出现**：Stage 2 起与虎鲸等可能刷新 Boss 房

**进攻**：
- 出 1/2/3 牌：抽取玩家牌库 1 张牌放入判定区判定；普通颜色造成对应数字🗡️并放回玩家牌库底，数字零/道具牌 0🗡️并置入玩家弃牌堆、跳过防御、获得 [潜水]、施加 [冰封]
- 出 4/5/6 牌：造成 **玩家手牌数**🗡️，施加 1 层[失温]
- 出 0 牌：施加 1 层[失温]，清除自身所有负面效果，造成 **3 + 清除层数**🗡️（<5 不可防御）

**防御**：
- 出 1/2/3 牌：反击 **½🗡️**（向上取整），获得 [潜水]
- 出 0 牌：**反击相同点伤害**（守护/飞翔结算前的点数），玩家选择 1 张手牌弃掉

**Stage 强化**：
- **Stage 2**：生命上限 +6（56）
- **Stage 3**：所有进攻技能伤害 <5 时均不可防御
- **Stage 4**：防御技能额外恢复 **1❤️**

### 掉落：投出1-2，掉落潜水战利白卡；投出3-4，掉落冰封战利白卡；投出5-6，掉落失温战利白卡

## 冻洋虎鲸（FrozenOrca）· Boss

**生命值**：40

**手牌上限**：3 张（牌堆含 2 张白 0 牌）

**进攻**：
- 出 1/2/3 牌：造成 **3🗡️**，获得 [潜水]（上限 1）；**防御阶段结束后**对对手施加 **1** 层[失温]
- 出 4/5/6 牌：造成 **5🗡️**，施加 **1** 层[流血]
- 出 0 牌：造成 **2 + 2 × 对手[流血]层数🗡️**

**防御**：
- 出 1/2/3 牌：**清除自身所有负面状态**，格挡 **½🗡️**（向上取整）
- 出 0 牌：**反击相同点伤害**（守护/飞翔结算前的点数），**清除自身所有负面状态**

**Stage 强化**：
- **Stage 2**：生命上限 +10（50）
- **Stage 3**：所有进攻伤害 +1
- **Stage 4**：防御 0 额外**免疫所有伤害**（仍反击相同伤害并清除负面状态）

### 掉落：投出1-3，掉落潜水战利白卡；投出4-5，掉落流血战利白卡；投出6，掉落失温战利白卡
