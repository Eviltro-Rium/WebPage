# 冻洋场景 · 怪物图鉴

所有怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 冻洋猞猁（FrozenOceanLynx）

### 生命值：20

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，施加[冷冻]
- 出 4/5/6 牌：造成 **4🗡️**，施加[冰封]

### 防御：

- 出 1/2/3 牌：防御**2🛡️**；若对手有[冷冻]，再反击 **2🗡️**

### Stage 强化：

- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有伤害 +1
- **Stage 4**：格挡与反击各 +1

### 掉落：投出1-2，掉落[冰冻]战利白卡；投出3-4，掉落[冰封]战利白卡

---

## 冻洋蓝鲸（FrozenWhale）

### 生命值：25

### 潜水（正面 buff）：

- 上限 **1** 层
- 持续 buff
- 免疫有效颜色为蓝色（含白色指定为蓝色）的攻击造成的伤害和随附的 buff 施加
- 对手依旧可以对自己施加正面增益

### 进攻：

- 出 1/2/3 牌：造成 **2🗡️**，获得 **1** 层[潜水]
- 出 4/5/6 牌：对场上所有其他角色（包括 NPC 队友）造成 **4🗡️**（不可防御）；**防御阶段结束后**对对手施加 **1** 层[失温]

### 防御：

- 出 1/2/3 牌：反击 **2🗡️**，获得 **1** 层[守护]

### Stage 强化：

- **Stage 2**：生命上限 +5（30）
- **Stage 3**：所有进攻伤害 +1
- **Stage 4**：防御反击 +1

### 掉落：投出1-2，掉落[潜水]战利白卡；投出3-4，掉落[失温]战利白卡

## 冻洋鲨（FrozenOceanShark）

### 生命值：27

### 出现条件：仅从 Stage 2 开始有几率出现

### 进攻：

- 出 4/5/6 牌：造成 **3🗡️**（不可防御），施加 **1** 层[流血]

### 防御：

- 出 1/2/3 牌：反击 **2🗡️**，施加 **1** 层[流血]

### Stage 强化：

- **Stage 3**：1/2/3 牌改为 **3 × 玩家[流血]层数🗡️**
- **Stage 4**：防御时额外防御**2🛡️**

### 掉落：投出1-4，掉落[流血]战利白卡

## 冻洋海豹（FrozenOceanSeal）

### 生命值：20

### 进攻：

- 出 1/2/3 牌：从怪物牌堆抽 1 张牌展示，造成对应数字的伤害（数字牌放入弃牌堆；魔法牌加入手牌）
- 出 4/5/6 牌：造成 **5🗡️**，施加[致盲]

### 防御：

- 出 1/2 牌：格挡 **½🗡️**（向上取整）
- 出 3 牌：反击**相同点伤害**（守护/飞翔结算前的点数）

### Stage 强化：

- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有进攻额外施加[冷冻]
- **Stage 4**：防御 3 额外**免疫所有伤害**（仍反击相同点伤害）

### 掉落：投出1-3，掉落[缴械]战利白卡

## 冻洋北极熊（FrozenPolarBear）

### 生命值：25

### 进攻：

- 出 1/2/3 牌：造成 **对手 buff 总层数🗡️**（正面+负面层数之和）
- 出 4/5/6 牌：造成 **5🗡️**，获得 1 层[暴击]（上限 2），施加 1 层[流血]

### 防御：

- 出 1/2/3 牌：格挡 **2🛡️**，施加 1 层[失温] + 1 层[流血]

### Stage 强化：

- **Stage 2**：生命上限 +5（30）
- **Stage 3**：4/5/6 伤害改为 **4🗡️**，流血改为 **2** 层
- **Stage 4**：格挡 +1（变为 3🛡️）

### 掉落：投出1-2，掉落[流血]战利白卡；投出3-4，掉落[失温]战利白卡

### Stage 强化：

- **Stage 4**：格挡 +1

## 冻洋虎鲸（FrozenOrca）· Boss

### 生命值：40

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，获得 [潜水]（上限 1）；**防御阶段结束后**对对手施加 **1** 层[失温]
- 出 4/5/6 牌：造成 **5🗡️**，施加 **1** 层[流血]
- 出 0 牌：先施加 **1** 层[流血]，然后造成 **2 + 2 × 对手[流血]层数🗡️**

### 防御：

- 出 1/2/3 牌：施加 **1** 层[流血]，格挡 **½🗡️**（向上取整）
- 出 0 牌：**反击相同点伤害**（守护/飞翔结算前的点数），**清除自身所有负面状态**

### Stage 强化：

- **Stage 2**：生命上限 +10（50）
- **Stage 3**：所有进攻伤害 +1
- **Stage 4**：防御 0 额外**免疫所有伤害**（仍反击相同伤害并清除负面状态）

### 掉落：投出1-3，掉落[潜水]战利白卡；投出4-5，掉落[流血]战利白卡；投出6，掉落[失温]战利白卡

## 冻洋猛犸（FrozenMammoth）· Boss

### 生命值：45

### 进攻：

- 出 1/2/3 牌：造成 **2🗡️**，获得 2 层[守护]，分别施加 1/2/3 层[流血]。先伤害，再施加效果
- 出 4/5/6 牌：造成 **3 + 对手[流血]层数🗡️**，扣血后施加 1 层[失温]
- 出 0 牌：施加 1 层[失温]，获得 4 层[守护]，造成 **3🗡️**（不可防御）。效果在防御阶段结束后、伤害结算前施加

### 防御：

- 出 1/2/3 牌：防御 **1/2🛡️**（向上取整），给攻击方施加 1 层[流血]
- 出 0 牌：**免疫所有伤害**，获得 2 层[守护]，给攻击方施加 2 层[流血]。不免疫对方技能的 buff 施加

### Stage 强化：

- **Stage 2**：生命上限 +10（55）
- **Stage 3**：所有进攻伤害 +1（1/2/3 为 3 点，4/5/6 为 4 + [流血]层数，0 为 4 点不可防御）
- **Stage 4**：所有有效防御额外施加 1 层[流血]（1/2/3 施加 2 层，0 施加 3 层）

### 掉落：投出1-3，掉落[流血]战利白卡；投出4-5，掉落[守护]战利白卡；投出6，掉落[失温]战利白卡；投出7-12，无掉落

## 克拉肯（FrozenKraken）· Boss

### 生命值：50

### 出现条件：仅从 Stage 2 开始有几率出现

### 进攻：

- 出 1/2/3 牌：抽取玩家牌库 1 张牌判定；🔴🟡🔵🟢造成对应数字🗡️，⚫⚪牌不造成伤害。伤害为 0（🔴🟡🔵🟢的零牌或⚫⚪牌）时置入玩家弃牌堆、跳过防御、获得 1 层[潜水]、施加 1 层[冰封]；伤害 > 0 时放回玩家牌库底
- 出 4/5/6 牌：造成玩家手牌数🗡️，施加 1 层[失温]
- 出 0 牌：施加 1 层[失温]，清除自身所有负面效果，造成 **3 + 清除层数🗡️**（伤害 <5 时不可防御）

### 防御：

- 出 1/2/3 牌：反击 **1/2🗡️**（向上取整），获得 1 层[潜水]
- 出 0 牌：**反击相同点伤害**（守护/飞翔结算前的点数），玩家选择 1 张手牌弃掉

### Stage 强化：

- **Stage 3**：伤害 <5 不可防御扩展为全牌适用
- **Stage 4**：防御恢复 **1❤️**


### 掉落：投出1-6，掉落[0技能]战利白卡

---

Boss 房从本场景 Boss 池 **等可能** 刷新一只（冻洋虎鲸 / 克拉肯 / 冻洋猛犸）。
克拉肯仅从 **Stage 2** 起出现。
