# 冻洋场景 · 怪物图鉴

所有怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](./buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

---

## 冻洋猞猁（FrozenOceanLynx）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：造成 **3🗡️**，施加【冷冻】
- 出 4/5/6 牌：造成 **4🗡️**，施加【冰封】

**防御**：
- 出 1/2/3 牌：🛡️**2🗡️**；若对手有【冷冻】，再反击 **2🗡️**

**Stage 强化**：
- **Stage 2**：生命上限 +5（25）
- **Stage 3**：所有伤害 +1
- **Stage 4**：格挡与反击各 +1

---

## 冻洋蓝鲸（FrozenWhale）

**生命值**：25

**被动**：拥有【潜水】时免疫蓝色攻击的伤害和 buff 施加。

**潜水（正面 buff）**：
- 上限 **1** 层
- 持续 buff
- 免疫有效颜色为蓝色（含白色指定为蓝色）的攻击造成的伤害和随附的 buff 施加
- 对手依旧可以对自己施加正面增益

**失温（负面 buff）**：
- 上限 **2** 层
- 衰减（防御阶段结束后结算）
- 冻洋蓝鲸进攻4/5/6时，**防御阶段结束后**才施加1层失温（而非进攻时立即施加）
- 当失温达到 **2 层**时，立即强制弃掉 1 张牌（玩家自选，NPC 自动按最低优先级弃牌），随后失温削减 1 层

**进攻**：
- 出 1/2/3 牌：造成 **2🗡️**，获得 **1** 层【潜水】
- 出 4/5/6 牌：对场上所有其他角色（包括 NPC 队友）造成 **4🗡️**（不可防御）；**防御阶段结束后**对对手施加 **1** 层【失温】

**防御**：
- 出 1/2/3 牌：反击 **2🗡️**，获得 **1** 层守护

**Stage 强化**：
- **Stage 2**：生命上限 +5（30）
- **Stage 3**：所有进攻伤害 +1

## 冻洋鲨（FrozenOceanShark）

**生命值**：20

**进攻**：
- 出 1/2/3 牌：造成 **2 × 玩家【流血】层数🗡️**
- 出 4/5/6 牌：造成 **3🗡️**（不可防御），施加 **1** 层【流血】

**防御**：
- 出 1/2/3 牌：反击 **2🗡️**，施加 **1** 层【流血】

**Stage 强化**：
- **Stage 2**：生命上限 +7（27）
- **Stage 3**：1/2/3 牌改为 **3 × 玩家【流血】层数🗡️**
- **Stage 4**：防御时额外🛡️**2🗡️**
