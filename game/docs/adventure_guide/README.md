## 怪物技能牌点（文档用语）

怪物 NPC 牌库已与 [`Cards_deck.md`](../reference/Cards_deck.md) 对齐：**白 0、白 1~5（5 为轮空）、魔法牌**。图鉴中的进攻/防御技能按 **0~5** 描述，不再使用旧的 1~7 七档。

与旧版图鉴技能的**文档映射**（实现改码前以本规则读档）：

| 旧出牌点数 | 新出牌点数 |
|-----------|-----------|
| 1、2、3 | **1**、**2**（原 3 点档合并入 2 点档，或与原 2 点档同列描述） |
| 4、5、6 | **3**、**4**（原 5 点档多合并入 4 点档；若原 4/6 不同则写「出3→原4、出4→原6」） |
| 7 | **5**（含白 7 轮空 → 白 5 轮空） |
| 0 | **0**（Boss / 特殊怪专属技能不变） |

本目录下各场景 `.md` 已按上表改写用语；个别怪物在「出3/出4」内仍用括号注明对应旧点数效果，便于与历史设计对照。
