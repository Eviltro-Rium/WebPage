# 火山场景 · 怪物图鉴

前四个怪物（火山蝾螈、熔岩蟹、灰烬狼、黑曜野猪）与三只 Boss（炎鬃狮 / 熔核犀 / 余烬凤凰）已接入冒险模式：技能、Stage 强化、Boss 池、掉落、图鉴和随机场景选择。地图 CSV 与背景已有资源。文档中另外六只普通怪仍待实现。本场景以 **[灼伤]**、**[炙热]** 施压，怪物常给自己挂攻击修正类正面 **[熔脉]**（攻击修正阶段可用即用，本次进攻伤害 ×1.5；本次技能新获得的熔脉不能在同一次进攻中回溯使用）。

除条目另有注明外，怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

### 物种去重说明

现有已实现的**灰烬狼**属于保留的既有角色，本次设计的六种新怪物均避开其他场景已用物种；后续扩展也应继续遵守此去重原则。

## 火山蝾螈（VolcanoSalamander）

### 生命值：20

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，施加 1 层[灼伤]
- 出 4/5/6 牌：造成 **5🗡️**，施加 1 层[灼伤]

### 防御：

- 出 1/2/3 牌：格挡至多 **2🛡️**，施加[炙热]

### Stage 强化：

- **Stage 2**：生命上限 +5（25）
- **Stage 3**：进攻技能伤害 **+1**
- **Stage 4**：防御格挡 +1

### 掉落：投出1-3，掉落[灼伤]战利白卡；投出4，掉落[炙热]战利白卡

## Boss · 炎鬃狮（VolcanoFlameLion）

### 生命值：40　　手牌上限：3

### 牌库：普通 NPC 牌库 + **2 张白色 0**

### 进攻：

- 出 1/2/3 牌：造成 **4🗡️**，施加 1 层[灼伤]
- 出 4/5/6 牌：造成 **3🗡️**（不可防御），施加[炙热]，获得[熔脉]
- 出 0 牌：先施加 **2** 层[灼伤]，再立刻进行一次[灼伤]结算（无卡面伤害）；获得[熔脉]

### 防御：

- 出 1/2/3 牌：格挡 **2🛡️**，施加 1 层[灼伤]
- 出 0 牌：**免疫所有伤害**（不免疫即将被施加的 debuff），施加[炙热]

### Stage 强化：

- **Stage 2**：生命上限 +10（50）
- **Stage 3**：进攻卡面伤害 +1（1/2/3 变为 5🗡️；4/5/6 变为 4🗡️ 不可防御；0 牌仍无卡面伤害，灼伤结算按施加后的层数）
- **Stage 4**：防御格挡 +1（变为 3🛡️）；防御 0 额外清除自身所有负面状态

### 掉落：投出1-4，掉落[灼伤]战利白卡；投出5-6，掉落[炙热]战利白卡

## Boss · 余烬凤凰（VolcanoCinderPhoenix）

### 生命值：50　　手牌上限：3

### 牌库：普通 NPC 牌库 + **2 张白色 0**

### 出现条件：仅在 **Stage 2/3/4** 刷出

### 被动：进攻开始之前，若自身没有任何[飞翔]，获得 1 层[飞翔]。

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，获得 1 层[飞翔]
- 出 4/5/6 牌：造成 **4🗡️**，施加 2 层[灼伤]与[炙热]
- 出 0 牌：施加[炙热]，恢复 **3❤️**，造成 **5🗡️**（不可防御）

### 防御：

- 出 1/2/3 牌：反击 **2🗡️**，对攻击方施加[炙热]
- 出 0 牌：**免疫所有伤害和即将被施加的 debuff**，清除自身所有 debuff，获得 1 层[飞翔]

### Stage 强化：

- **Stage 2**：以 50 生命进入（本 Boss 不在 Stage 1 出现）
- **Stage 3**：进攻卡面伤害 +1（1/2/3 变为 4🗡️；4/5/6 变为 5🗡️；0 变为 6🗡️ 不可防御）
- **Stage 4**：防御反击 +1（变为 3🗡️）；防御 0 额外恢复 **2❤️**

### 掉落：投出1-3，掉落[飞翔]战利白卡；投出4-5，掉落[炙热]战利白卡；投出6，掉落[灼伤]战利白卡

## 实现与怪物池

- `adventure/js/monsters/volcano.js` 注册前四个怪物、三只 Boss，以及 Stage 1-4 通用怪物池与 Boss 池；文档中的另外六只普通怪仍待实现。
- Boss 房从本场景 Boss 池 **等可能** 刷新一只（炎鬃狮 / 熔核犀 / 余烬凤凰）。余烬凤凰仅从 **Stage 2** 起出现。
- 战利白卡掉落已接入 `adventure/js/engine/loot.js` 的 `SCENE_RULES.volcano`，按各怪物独立的 12 面骰规则结算；Boss 掉落上限为 **6/12**。
- 灰烬狼防御：先施加灼伤，再结算一次灼伤；Stage 4 额外炙热在这次结算后施加，不提供普通格挡。
- 熔岩蟹 / 炎鬃狮 / 熔核犀本次技能获得的熔脉留给之后的进攻使用，不能在获得它的同一次进攻中回溯使用。
- 对应图标使用 `volcano_salamander.webp`、`volcano_crab.webp`、`volcano_wolf.webp`、`volcano_boar.webp`、`volcano_lion.webp`、`volcano_rhino.webp`、`volcano_phoenix.webp`。
- **[熔脉]** 的图标、统一修正弹窗、引擎结算与战利白卡已接入，规则见 [buff_guide.md](../buff_guide.md)。图标 `icons/buff_icons/magma_vein.webp`。
