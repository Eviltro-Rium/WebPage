# 火山场景 · 怪物图鉴

普通怪物在 Stage 1-4 均可出现，黑曜犰狳和硫晶鼬从 Stage 2 起出现。怪物按 Stage 逐级强化（累积叠加），具体规则以各条目为准。本场景主要通过[灼伤]、[炙热]施压；[熔脉]是攻击修正类正面状态，在攻击修正阶段生效，本次进攻中新获得的[熔脉]不能回溯强化当前攻击。

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 火山蝾螈（VolcanoSalamander）

### 生命值：20

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，施加 1 层[灼伤]
- 出 4/5/6 牌：造成 **5🗡️**，施加 1 层[灼伤]

### 防御：

- 出 1/2/3 牌：格挡至多 **2🛡️**，施加[炙热]

### Stage 强化：

- **Stage 2**：生命上限 +5（25）
- **Stage 3**：进攻技能伤害 **+1**
- **Stage 4**：防御格挡 +1

### 掉落：投出1-3，掉落[灼伤]战利白卡；投出4，掉落[炙热]战利白卡

## Boss · 炎鬃狮（VolcanoFlameLion）

### 生命值：40　

### 进攻：

- 出 1/2/3 牌：造成 **4🗡️**，施加 1 层[灼伤]
- 出 4/5/6 牌：造成 **3🗡️**（不可防御），施加[炙热]，获得[熔脉]，施加 1 层[灼伤]
- 出 0 牌：先施加 **2** 层[灼伤]，再立刻进行一次[灼伤]结算（无卡面伤害）；获得[熔脉]

### 防御：

- 出 1/2/3 牌：格挡 **3🛡️**，施加 1 层[灼伤]
- 出 0 牌：**免疫所有伤害**（不免疫即将被施加的 debuff），施加[炙热]

### Stage 强化：

- **Stage 2**：生命上限 +10（50）
- **Stage 3**：进攻卡面伤害 +1
- **Stage 4**：防御格挡 +1（变为 4🛡️）；0技能，施加 2 层[灼伤]

### 掉落：投出1-4，掉落[灼伤]战利白卡；投出5-6，掉落[炙热]战利白卡

## Boss · 熔核犀（VolcanoMagmaRhino）

### 生命值：45

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，获得 1 层[守护]，施加[流血]
- 出 4/5/6 牌：造成 **5🗡️**，该牌被指定为🔴时变为不可防御，否则获得[熔脉]
- 出 0 牌：造成 **6🗡️**；若自身已有[熔脉]，该伤害变为不可防御。
### 防御：

- 出 1/2/3 牌：格挡伤害的一半（向上取整），获得 1 层[熔脉]
- 出 0 牌：反击 **相同点🗡️**，施加2层[流血]

### Stage 强化：

- **Stage 2**：生命上限 +10（55）
- **Stage 3**：进攻卡面伤害 +1
- **Stage 4**：防御0固定反击 **2🗡️**

### 掉落：投出1-3，掉落[熔脉]战利白卡；投出4-5，掉落[流血]战利白卡；投出6，掉落[守护]战利白卡

## Boss · 余烬凤凰（VolcanoCinderPhoenix）

### 生命值：35

### 出现条件：仅在 **Stage 2/3/4** 刷出

### 被动：生命值第一次降至0时，恢复至15❤️，手牌补至4张；手牌上限仍为3。

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，获得 1 层[飞翔]
- 出 4/5/6 牌：造成 **4🗡️**，施加 2 层[灼伤]与[炙热]
- 出 0 牌：施加[炙热]，恢复 **3❤️**，造成 **5🗡️**（不可防御）

### 防御：

- 出 1/2/3 牌：反击 **2🗡️**，对攻击方施加[炙热]
- 出 0 牌：**免疫所有伤害和即将被施加的 debuff**，清除自身所有 debuff，获得 1 层[飞翔]

### Stage 强化：

- **Stage 3**：进攻卡面伤害 +1
- **Stage 4**：防御技能额外恢复 **2❤️**

### 掉落：投出1-3，掉落[飞翔]战利白卡；投出4-5，掉落[炙热]战利白卡；投出6，掉落[灼伤]战利白卡

## 怪物池

- 普通怪物和 Boss 仅从火山场景各自的怪物池抽取。Stage 1 普通怪物池包含火山蝾螈、熔岩蟹、灰烬狼、黑曜野猪、熔渣獾、玄岩蜈蚣和熔岩蛞蝓；Stage 2-4 额外加入黑曜犰狳与硫晶鼬。
- Boss 房从本场景 Boss 池等概率刷新一只（炎鬃狮 / 熔核犀 / 余烬凤凰）；余烬凤凰仅从 Stage 2 起出现。
- 战利白卡掉落规则按各怪物独立的 12 面骰结果结算，普通怪物成功范围不超过 4/12，Boss 不超过 6/12。
- 灰烬狼防御：先施加[灼伤]并立刻结算；Stage 4 额外施加的[炙热]在结算后生效，因此不提供普通格挡。
- [熔脉]的图标、攻击修正和战利白卡规则见 [buff_guide.md](../buff_guide.md)；图标为 `game/icons/buff_icons/magma_vein.webp`。
- 火山怪物头像统一使用 `game/icons/npc_icons/volcano_*.webp`，规格为 **64×64**。
