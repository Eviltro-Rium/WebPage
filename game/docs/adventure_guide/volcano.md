# 火山场景 · 怪物图鉴

场景规划中（地图 CSV、背景图、怪物池注册、掉落规则分组待接入）。本场景以 **[灼伤]**、**[炙热]** 施压，怪物常给自己挂独立正面 **[熔脉]**（下次进攻伤害 ×1.5）。

所有怪物在 Stage 1-4 均可出现，按 stage 逐级强化（累积叠加）：

| Stage | 强化方向 |
|-------|---------|
| 1 | 基础属性 |
| 2 | 增加生命上限 |
| 3 | 增加伤害 |
| 4 | 加强防御 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

## 场景专属状态 · [熔脉]

- **类型**：**正面 · 攻击修正类 Buff** · 上限 **1** · 图标 `buff_icons/magma_vein.webp`
- **效果**：攻击修正阶段消耗后，本次进攻伤害 **×1.5（向上取整）**；与[暴击]、攻击修正道具互斥不可叠用。
- **操作**：玩家与[暴击]同弹窗；NPC 可用即用，且优先于暴击。时机在攻击修正道具之前。
- **独立**：不与[灼伤]/[炙热]联动。

## 火山蝾螈（VolcanoSalamander）

### 生命值：20

### 进攻：

- 出 1/2/3 牌：造成 **3🗡️**，施加 1 层[灼伤]
- 出 4/5/6 牌：造成 **2🗡️**（不可防御），施加 2 层[灼伤]

### 防御：

- 出 1/2/3 牌：格挡至多 **2🛡️**，施加 1 层[灼伤]

### Stage 强化：

- **Stage 2**：生命上限 +5（25）
- **Stage 3**：进攻技能伤害 **+1**
- **Stage 4**：防御格挡 +1

### 掉落：投出1-4，掉落[灼伤]战利白卡
