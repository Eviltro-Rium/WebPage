# 战利白卡掉落规则

战利白卡不再从普通商店、普通房奖励、挑战房奖励或奖励房奖励池中出现。

## 获取途径

- 击败城堡场景中的怪物后，立即投掷一次 12 面骰。
- 掷骰结果命中怪物规则时，战利白卡直接加入玩家当前战斗手牌；战斗结束后随玩家牌库状态保存。
- 1v2 中某个怪物出局时立即单独结算该怪物的掉落，两个怪物共用牌库但各自只结算一次。
- 铁匠铺的战利白卡摊位仍可使用对应兽元锻造。

## 城堡场景

| 怪物 | 掷骰结果 | 掉落 |
| --- | --- | --- |
| 城堡幽灵 | 1–3 | 飞翔战利白卡 |
| 萤火虫 | 1–2 | 飞翔战利白卡 |
| 狼 | 1–2 | 守护战利白卡 |
| 狐 | 1–2 | 流血战利白卡 |
| 熊 | 1–3 | 守护战利白卡 |
| 虎 | 1–3 | 流血战利白卡 |
| 鸦 | 1–2 | 缴械战利白卡 |
| 蝠 | 1–2 | 流血战利白卡 |
| 哥布林 | 1 | 缴械战利白卡 ×2 |
| 隐之避役 | 1–6 | 中毒战利白卡 |
| 自由之鹰 | 1–6 | 俄罗斯赌盘战利白卡 |
| 石像鬼 | 1–4 | 0 技能战利白卡 |

规则集中实现于 `adventure/js/engine/loot.js`，战斗引擎只负责调用规则、把实体卡加入手牌并传递结算记录；这样后续新增场景时无需把掉落判断散落到商店或奖励代码中。
