# 战利白卡掉落规则

击败怪物后投掷 **D12**，按该怪物掉落表结算。实现见 `adventure/js/engine/loot.js`（`SCENE_RULES` / `rollMonsterDrop`）。

## 通用掉落（所有场景 · 所有怪物含 Boss）

| 点数 | 掉落 |
|------|------|
| **11** | [小药剂]战利白卡（`SmallPotionTrophy`，双源） |
| **12** | [净化之水]战利白卡（`PurifyWaterTrophy`，双源） |

11 / 12 与各怪物专属成功区间互不占用。

每次投骰后，下方结算弹窗显示完整掉落表并高亮命中点数。获得白卡时先播放入手动画；无论是否获得白卡，都需玩家点击「确认」后才继续下一次投骰或后续奖励结算。Boss 的三次投骰分别确认。

挑战房首只怪物被击败时也独立结算一次：先完成出局与恢复反馈，再投战利品骰。玩家确认后收起弹窗、清理骰子展示并继续对战；等待确认期间，存活敌人的后续行动暂停。

## 专属掉落上限

- 普通怪物专属成功范围不超过 **4/12**
- Boss 专属成功范围不超过 **6/12**
- 上述上限**不**限制通用的 11 / 12
各场景明细：

- [城堡](castle.md)
- [丛林](forest.md)
- [冻洋](ocean.md)
- [沙漠](desert.md)
- [火山](volcano.md)

战利白卡：`drop` 仅掉落 · `forge` 仅铁匠（俄盘/缴械/**暴乱**）· `both` 双源（小药剂/净化/零技能）。铁匠槽 = forge∪both。细则见 [consumables.md](consumables.md)。
