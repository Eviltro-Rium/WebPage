# 🐼 Ryan

- **初始血量**：50
- **被动**：在我方⚔️回合开始前恢复1❤️

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 1❤️，抽1🃏（跳过防御） |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 再打1张数字牌：选择恢复对应数字+3❤️，或造成对应数字+3🗡️ |
| 4️⃣ | 4🗡️，选择清除自身 1 层可净化状态（正面或负面），抽1🃏 |
| 5️⃣ | 造成手牌所有数字之和🗡️（道具牌不算点数） |
| 0️⃣ | 清除自身所有⬇️debuff，抽2🃏并公示，施加对应数字之和🗡️（道具牌算3点），两张牌收入手牌 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 防御1/2🛡️（向上取整） |
| 2️⃣ | 反击2🗡️，恢复2❤️ |
| 0️⃣ | 清除自身所有⬇️debuff，免疫伤害和即将被施加的debuff，恢复3❤️ |

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
