# 🐼 Ryan

- **初始血量**：70
- **被动**：在我方⚔️回合开始前恢复1❤️

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 4🗡️ |
| 2️⃣ | 1❤️，3🗡️ |
| 3️⃣ | 1❤️，抽1🃏，可选择弃牌 |
| 4️⃣ | 翻开牌库顶第一张牌判定：若为🟢/⚪/⚫→恢复1❤️+4🗡️，该牌加入手牌；否则加入手牌 |
| 5️⃣ | 再打1张数字牌：恢复对应数字❤️，或造成对应数字×1.5（向上取整）🗡️ |
| 6️⃣ | 4🗡️，清除自身所有⬇️debuff，抽1🃏 |
| 7️⃣ | 造成手牌所有数字之和½（向上取整）🗡️（道具牌不算点数） |
| 0️⃣ | 4❤️，清除自身所有⬇️debuff，抽2🃏并公示，施加对应数字之和🗡️（道具牌算4点），两张牌收入手牌 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 🛡️½（向上取整）🗡️ |
| 2️⃣ | 反击2🗡️，恢复2❤️ |
| 3️⃣ | 无视🔴色攻击；其他颜色→恢复3❤️ |
| 0️⃣ | 清除自身所有⬇️debuff，免疫伤害，恢复3❤️ |

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
