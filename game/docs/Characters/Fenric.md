# 🐺 Fenric

- **初始血量**：70
- **被动**：所有技能对Fenric造成伤害时，超过7🗡️自动截断。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️，获得[守护] |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 4🗡️ ，若此牌为🔴，获得[硬化]；🔵，则施加[失温]；其他，伤害+1 |
| 4️⃣ | 翻开牌库1🃏入判定区，造成对应数字点🗡️(至少为3点) ，获得[硬化]，判定牌随后入弃牌库 |
| 5️⃣ | 2🗡️，抽取1🃏，获得2层[守护]，随后每有一层[守护]，恢复1❤️|
| 0️⃣ | 获得2层[守护]，造成2+[守护]层数点🗡️，有[硬化]时变为不可防御攻击。 |



## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 防御1/2（向上取整）🛡️，施加[失温] |
| 2️⃣ | 获得3层[守护] |
| 0️⃣ | 反弹所有伤害，buff效果不反弹 |

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
