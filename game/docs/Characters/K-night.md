# 🐺 K-night

- **初始血量**：80
- **被动**：每次进攻回合之前清除所有【混沌】（正面buff），进攻或防御时打出基础颜色（红黄蓝绿）数字牌时，可获得对应颜色的混沌（每种颜色上限为1层，黑白牌无效），混沌获得结算在对手防御完成或跳过防御后进行。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 1🗡️（不可防御），若有【混沌🟢】恢复1❤️，获得1层【守护】；若有【混沌🔴】施加2层【灼伤】；若有【混沌🔵】，施加【冰冻】；若有【混沌🟡】施加1层【流血】。（可叠加） |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 3🗡️，若同时拥有【混沌🟢】和【混沌🟡】，则恢复3❤️ |
| 4️⃣ | 抽取牌库顶一张牌进行判定，若是数字且<4，造成4🗡️；若是数字且>=4，或是道具牌（除数字以外的黑/白牌，包括战利白牌），则造成6🗡️。若有【混沌🔵】判定牌加入手牌，否则判定牌入弃牌库底 |
| 5️⃣ | 5🗡️，若有【混沌🔴】，则变为不可防御伤害 |
| 6️⃣ | 2🗡️，并获得2层【守护】，若有【混沌🟢】则额外获得2层【守护】 |
| 7️⃣ | 造成4+【混沌】总数×2🗡️，然后清除所有【混沌】。（打出的7️⃣，正常结算【混沌】的获得） |
| 0️⃣ | 若有4种【混沌】，改为对所有对手造成8🗡️（不可防御）；否则补齐4种【混沌】，对单一目标造成6🗡️（可防御） |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 恢复2❤️，若有【混沌🟡】再反击2🗡️ |
| 2️⃣ | 🛡️½（向上取整）🗡️，若有【混沌🔵】再抽取1🃏 |
| 3️⃣ | 🛡️½（向上取整）🗡️，若有【混沌🔴】施加2层【灼伤】 |
| 0️⃣ | 每有一种【混沌】吸取2❤️。若有4种【混沌】，免疫本次攻击所有伤害；否则补齐4种【混沌】 |

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
