# 🐺 K-night

- **初始血量**：70
- **被动**：每次进攻回合之前清除所有[混沌]（正面buff），进攻或防御时打出数字牌或白色道具牌可获得对应颜色的混沌（每种颜色上限为1层；黑/白牌按其指定颜色结算）。数字牌的混沌获得结算在对手防御完成或跳过防御后进行；白色道具牌在打出时立即获得。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 1🗡️（不可防御），若有[混沌🟢]恢复1❤️，获得1层[守护]；若有[混沌🔴]施加2层[灼伤]；若有[混沌🔵]，施加[冷冻]；若有[混沌🟡]施加1层[流血]。（可叠加） |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 5🗡️，若有[混沌🔴]，则变为不可防御伤害 |
| 4️⃣ | 4🗡️，并获得2层[守护]，若有[混沌🟢]则额外获得2层[守护] |
| 5️⃣ | 造成4+[混沌]总数×2🗡️，然后清除所有[混沌]。（打出的7️⃣，正常结算[混沌]的获得） |
| 0️⃣ | 若有4种[混沌]，改为对所有对手造成8🗡️（不可防御）；否则补齐4种[混沌]，对单一目标造成6🗡️（可防御） |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 恢复2❤️，若有[混沌🟡]再反击2🗡️ |
| 2️⃣ | 防御1/2🛡️（向上取整），若有[混沌🔵]再抽取1🃏 |
| 0️⃣ | 每有一种[混沌]吸取2❤️。若有4种[混沌]，免疫本次攻击所有伤害；否则补齐4种[混沌] |

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
