# 🐶 Serenity

- **初始血量**：80
- **被动**：免疫【冷冻】；❤️<30时进入【嗜血】态（非buff，无法清除）；❤️>=30时正常状态，恢复时额外+1❤️

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 3🗡️；【嗜血】时跳过防御 |
| 2️⃣ | 3🗡️；【嗜血】时改为5🗡️ |
| 3️⃣ | 2🗡️，恢复2❤️ |
| 4️⃣ | 5🗡️；【嗜血】时先施加1层【流血】再造成5🗡️ |
| 5️⃣ | 翻开牌库顶1张牌：黄/绿→恢复4❤️（跳过防御）；否则→对对手5🗡️；弃掉该牌 |
| 6️⃣ | 6🗡️；【嗜血】时不可防御 |
| 7️⃣ | 对自己2🗡️+对所有对手5🗡️（不可防御，AOE）；【嗜血】时自己不受伤害 |
| 0️⃣ | 恢复1❤️，弃掉所有手牌，每弃1张+3❤️（上限9），重抽4张继续⚔️；【嗜血】时对手也弃所有手牌并抽原数-1张 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 🛡️至多3🗡️；【嗜血】时额外恢复实际防御点数❤️ |
| 2️⃣ | 对进攻方施加1层【流血】，每层【流血】吸取2❤️ |
| 3️⃣ | 🛡️½（向上取整）🗡️；【嗜血】时多🛡️2🗡️ |
| 0️⃣ | 翻开牌库顶1张牌：黄→进攻方⚔️结束后❤️减半（非伤害）；否则→免疫所有伤害和debuff；弃掉该牌 |

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
