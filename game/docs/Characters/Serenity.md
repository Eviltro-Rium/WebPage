# 🐶 Serenity

- **初始血量**：75
- **冒险房间结算**：普通房胜利后不获得通用的 +3❤️「战斗恢复」。生命核心、药剂、挑战房首个敌人的回复及跨层回复照常结算。
- **被动**：免疫[冷冻]；❤️<30时获得[嗜血]印记。同一场战斗内恢复生命不会移除印记；冒险离开房间并结算恢复后，生命高于30则清除，恰好30时保留；不能被净化或超级净化清除；尚未获得印记时，正常恢复额外+1❤️。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️，恢复2❤️；[嗜血时]2🗡️，施加2层[流血]|
| 2️⃣ | 3🗡️；[嗜血]时改为5🗡️ |
| 3️⃣ | 3🗡️；[嗜血]时跳过防御 |
| 4️⃣ | 5🗡️；[嗜血]时先施加1层[流血]再造成5🗡️ |
| 5️⃣ | 翻开牌库顶1张牌：黄/绿→恢复4❤️（跳过防御）；否则→对对手5🗡️；弃掉该牌 |
| 6️⃣ | 6🗡️，并选1🃏弃掉 |
| 7️⃣ | 对自己2🗡️+对所有对手5🗡️（不可防御，AOE）；[嗜血]时自己不受伤害 |
| 0️⃣ | 恢复1❤️，弃掉所有手牌，每弃1张+3❤️（上限9），重抽4张继续⚔️（跳过防御）；[嗜血]时对手也弃所有手牌并抽原数-1张 |

0 技能弃掉的牌全部进入所属角色的弃牌库，可正常洗回抽取。归零战利白卡触发同一规则，技能不会减少牌组总数。

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 防御至多3🛡️ |
| 2️⃣ | 对进攻方施加1层[流血]，每层[流血]吸取1❤️ |
| 3️⃣ | 防御1/2🛡️（向上取整）；[嗜血]时额外反击2🗡️ |
| 0️⃣ | 翻开牌库顶1张牌：黄→进攻方⚔️结束后❤️减半（非伤害）；否则→免疫所有伤害和debuff；弃掉该牌 |
