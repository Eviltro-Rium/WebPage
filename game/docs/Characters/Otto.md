# 🐶 Otto

- **初始血量**：80
- **被动**：多人模式下当Serenity是Otto队友时，Serenity受到超过6🗡️伤害时，超出部分由Otto承担（不进行防御出牌），且自动防御1/2🛡️（向上取整），Serenity仍可以对6🗡️伤害做出防御。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️，获得1层[守护]，获得1层[暴击] |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 先获得1层[暴击]，再造成5🗡️ |
| 4️⃣ | 再选择打出一张数字牌进行判定（结束后放回弃牌库底），若判定为🔴🟡🔵🟢，则造成对应数字+2点🗡️；若为⚪，则恢复对应数字+2点❤️，并获得1层[暴击]（跳过防御） |
| 5️⃣ | 造成自身血量/8（双雄模式因初始生命翻倍改为/16，向上取整）点🗡️；冒险挑战房仍按/8；伤害≤3时不可防御 |
| 0️⃣ | 4🗡️。每拥有1层[暴击]额外+3🗡️；无[暴击]时，该伤害不可防御 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 反击2🗡️，获得1层[守护] |
| 2️⃣ | 恢复2❤️，施加2层[流血] |
| 0️⃣ | 获得5层[守护]，反击相同点🗡️ |

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
