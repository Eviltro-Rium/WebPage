# 🐶 Otto

- **初始血量**：100
- **被动**：多人模式下当Serenity是Otto队友时，Serenity受到超过6🗡️伤害时，超出部分由Otto承担，且自动防御1/2🛡️（向上取整），Serenity仍可以对6🗡️伤害做出防御。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️（不可防御），获得1层【暴击】 |
| 2️⃣ | 3🗡️，获得1层【守护】 |
| 3️⃣ | 4🗡️ |
| 4️⃣ | 翻开牌库顶两张牌进行判定（判定后放回牌库顶）：两张均为数字牌→造成数字之和🗡️；1张道具牌→造成另一张数字½（向上取整）🗡️（不可防御）；两张道具牌→吸取3❤️（不可防御） |
| 5️⃣ | 再选择打出一张数字牌进行判定（结束后放回弃牌库底），若判定为🔴🟡🔵🟢，则造成对应数字×1.5（向上取整）点🗡️；若为⚪，则恢复对应数字×1.5（向上取整）点❤️，并获得1层【暴击】（跳过防御） |
| 6️⃣ | 6🗡️，自伤1🗡️，获得1层【暴击】 |
| 7️⃣ | 造成自身血量/10（双雄模式因初始生命翻倍改为/20，向上取整）点🗡️；冒险挑战房仍按/10；伤害≤3时不可防御 |
| 0️⃣ | 4🗡️。每拥有1层【暴击】额外+3🗡️；无【暴击】时，该伤害不可防御 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 防御1/2🛡️（向上取整）；可以使用2层【暴击】来返还这防御的伤害 |
| 2️⃣ | 反击2🗡️，获得1层【守护】 |
| 3️⃣ | 恢复2❤️，施加2层【流血】 |
| 0️⃣ | 获得5层【守护】，反击相同点🗡️ |

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
