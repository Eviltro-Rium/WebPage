# 🐶 Vixraps（设计中）

- **初始血量**：85
- **被动**：打出黑牌后，在搭桥出牌之前，必须弃掉1张牌，然后恢复3点❤️。如果打出黑牌后没有手牌，则不需要弃牌，还是可以恢复3点❤️。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️（不可防御），施加2层【灼伤】 |
| 2️⃣ | 3🗡️，（在对手防御之前）打开普通净化弹窗，选择自身1层状态清除，也可以选择不清理 |
| 3️⃣ | 4🗡️ |
| 4️⃣ | 恢复1/2 对手【灼伤】层数（向上取整）点❤️，然后抽取1🃏|
| 5️⃣ | 5🗡️ ，对手【灼烧】层数翻倍（不能超限） |
| 6️⃣ | 施加1层【灼伤】，对手触发一次【灼伤】结算，恢复【灼伤】伤害等量点❤️ |
| 7️⃣ | 施加【催眠】和２层【灼伤】，造成对手【灼伤】层数×２点🗡️　|
| 0️⃣ | 对目标施加【催眠】，对所有对手施加2层【灼伤】，然后所有对手连续结算两次【灼伤】伤害　|

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 反击2🗡️，施加2层【灼伤】 |
| 2️⃣ | 对手【灼伤】层数先翻倍，随后对手每有1层【灼伤】恢复1❤️ |
| 3️⃣ | 反击1/2（向上取整）点🗡️，恢复1点❤️ |
| 0️⃣ | 施加【催眠】和【灼伤】，防御1/2（向上取整点）🛡️，对方每有1层【灼伤】恢复2点❤️ |

## 【催眠】与【沉睡】机制

Vixraps 专属的两阶段 debuff，详见 [buff_guide.md](../buff_guide.md)。

- **【催眠】**（阶段一）：纯标记。持有者自己的进攻阶段结束、对手进攻阶段开始时立即转化为【沉睡】；施加后的当前攻击不会立即转化。重复施加无效。
- **【沉睡】**（阶段二）：由【催眠】转化。持有者无法打出防御牌（强制跳过防御，全额承伤）；免疫新催眠；进入自己攻击回合时苏醒并恢复 10❤️（受 maxHp 上限）。

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
