# 🐶 Blaze

- **初始血量**：65
- **被动**：当你[灼伤]时，你的⚔️阶段的所有攻击+1🗡️（参与🛡️的计算），该伤害加成不能叠加

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 3🗡️，然后对自己和对手施加1层[灼伤]|
| 2️⃣ | 4🗡️ |
| 3️⃣ | 对自己施加1层[灼伤]，然后造成2+[灼伤]层数🗡️（含被动加成） |
| 4️⃣ | 恢复 1+自身[灼伤]层数❤️，并对对手施加1层[灼伤]，清除所有[灼伤]（跳过防御） |
| 5️⃣ | 先对双方各施加2层[灼伤]，然后对目标造成场上所有[灼伤]层数（向上取整）🗡️（含被动加成） |
| 0️⃣ | 对除自己以外，所有玩家造成5🗡️（不可防御），并施加2层[灼伤]|

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 恢复自身[灼伤]层数❤️，之后对双方各施加1层[灼伤] |
| 2️⃣ | 对进攻玩家施加2层[灼伤]，防御1/2🛡️（向上取整） |
| 0️⃣ | 对进攻玩家施加5层[灼伤]，恢复场上所有[灼伤]数+3❤️，（先施加灼伤再结算回血） |

## 备注

- 1️⃣在伤害结算后施加灼伤。3️⃣和5️⃣先施加灼伤，再按当前层数计算伤害及被动加成。

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
