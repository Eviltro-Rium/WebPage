# 🐶 Blaze

- **初始血量**：85
- **被动**：当你[灼伤]时，你的⚔️阶段的所有攻击+1🗡️（参与🛡️的计算），该伤害加成不能叠加

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️（不可防御），然后对自己施加2层[灼伤] |
| 2️⃣ | 3🗡️，然后对自己和对手施加1层[灼伤]|
| 3️⃣ | 4🗡️ |
| 4️⃣ | 从攻击目标的手牌中抽取一张牌（冒险模式由玩家选择，其他模式系统随机；入判定区）：若没有点数或点数为0️⃣，造成4🗡️，双方各获得1层[灼伤]；否则造成对应点数🗡️。然后弃掉该牌。自身原有[灼伤]时伤害受被动加成 |
| 5️⃣ | 对自己施加1层[灼伤]，然后造成2+[灼伤]层数🗡️（含被动加成） |
| 6️⃣ | 恢复 1+自身[灼伤]层数❤️，并对对手施加1层[灼伤]，清除所有[灼伤]（跳过防御） |
| 7️⃣ | 先对双方各施加2层[灼伤]，然后对目标造成场上所有[灼伤]层数（向上取整）🗡️（含被动加成） |
| 0️⃣ | 对除自己以外，所有玩家造成5🗡️（不可防御），并施加2层[灼伤]|

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 恢复自身[灼伤]层数❤️，之后对双方各施加1层[灼伤] |
| 2️⃣ | 对进攻玩家施加2层[灼伤]，防御1/2🛡️（向上取整） |
| 3️⃣ | 对进攻玩家施加2层[灼伤]，反击对手[灼伤]层数🗡️，（先施加灼伤再结算伤害） |
| 0️⃣ | 对进攻玩家施加5层[灼伤]，恢复场上所有[灼伤]数+3❤️，（先施加灼伤再结算回血） |

## 备注

- 被动加成在1️⃣2️⃣3️⃣4️⃣5️⃣6️⃣7️⃣的攻击伤害中生效
- 5️⃣和7️⃣先施加灼伤再计算伤害，因此被动加成保证生效
- 4️⃣抽到无点数牌或0️⃣时，伤害结算后双方各获得1层[灼伤]；新获得的[灼伤]不影响本次伤害
- 防御1️⃣2️⃣3️⃣0️⃣均涉及灼伤施加，先施加灼伤再结算后续效果

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)。
