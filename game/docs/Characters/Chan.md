# 🐼 Chan

- **初始血量**：60
- **被动**：在进攻回合开始前可以抽取一张牌。（回合结束时手牌依旧不能超过5张）

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 1🗡️（不可防御），施加[冷冻] |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 消耗2❤️，查看[牌库顶]5🃏，并交换顺序后放回[牌库顶]，然后抽取2🃏（跳过防御） |
| 4️⃣ | 5🗡️，并抽取1🃏，若是🔵/⚪/⚫则不能被防御，随后判定牌进入弃牌堆；否则将判定牌加入手牌 |
| 5️⃣ | 6🗡️，冒险模式由玩家选择对手一张手牌，展示后放入 NPC 弃牌库；其他模式系统随机抽取对手一张牌展示，可选择弃掉或加入自己手牌 |
| 0️⃣ | 7🗡️，施加[冷冻]，抽取1🃏 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 反击2🗡️，并施加[冷冻] |
| 2️⃣ | 翻开[牌库顶]1🃏，恢复½对应点数❤️（向上取整，道具牌算0点），然后加入手牌 |
| 0️⃣ | 防御所有伤害🛡️（不免疫⬇️buff），并反击所受伤害1/2🗡️，进攻方立刻结束回合 |

## [冷冻]效果

- ⬇️buff，有该buff的玩家不能防御🔵属性攻击（包括被指定为蓝色的白色牌）
- 最多叠1层，持续直到被清除

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
