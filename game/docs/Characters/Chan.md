# 🐼 Chan

- **初始血量**：80
- **被动**：在进攻回合开始前可以抽取一张牌。（回合结束时手牌依旧不能超过5张）

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 1🗡️，施加【冷冻】（跳过防御） |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 2🗡️，抽取1🃏 |
| 4️⃣ | 抽取对手1张手牌，选择用你的1张手牌强制交换；若不交换，则该玩家弃掉该牌并造成2🗡️（跳过防御） |
| 5️⃣ | 消耗2❤️，查看【牌库顶】5🃏，并交换顺序后放回【牌库顶】，然后抽取2🃏（跳过防御） |
| 6️⃣ | 5🗡️，并抽取1🃏，若是🔵/⚪/⚫则不能被防御（跳过防御），无论判定结果如何都要将判定牌加入手牌 |
| 7️⃣ | 6🗡️，选择对手一张牌放入判定区展示，可以选择放入弃牌库，也可以选择加入自己手牌 |
| 0️⃣ | 7🗡️，施加【冷冻】，抽取1🃏 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 🛡️½（向上取整）🗡️ |
| 2️⃣ | 反击2🗡️，并施加【冷冻】 |
| 3️⃣ | 翻开【牌库顶】1🃏，恢复½对应点数❤️（向上取整，道具牌算0点），然后加入手牌 |
| 0️⃣ | 🛡️所有伤害（不免疫⬇️buff），并反击所受伤害½🗡️，进攻方立刻结束回合 |

## 【冷冻】效果

- ⬇️buff，有该buff的玩家不能防御🔵属性攻击（包括被指定为蓝色的白色牌）
- 最多叠1层，持续直到被清除

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
