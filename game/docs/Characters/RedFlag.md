# 🐺 RedFlag

- **初始血量**：60
- **类型**：战士
- **被动**：对手因为[失温]而弃牌时，自己抽1🃏。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 抽1🃏，施加[失温] |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 对手每有一张手牌，造成1🗡️，伤害 < 4时施加[失温] |
| 4️⃣ | 4🗡️，目标有[失温]时变为不可防御 |
| 5️⃣ | 抽取对手1牌，造成对应数字+3🗡️，然后弃掉该牌 |
| 0️⃣ | 7🗡️。对手防御前，RedFlag 可弃掉自己的全部手牌并抽取等量🃏 |

- 备注：
  - 进攻3️⃣在打出进攻牌后、防御前锁定对手手牌数；失温条件也按锁定的技能伤害判断。
  - 进攻5️⃣在冒险模式由玩家选择对手手牌，其余模式由系统随机抽取。选中的牌放入判定区展示，防御结束后进入原持有者的弃牌库。没有点数的牌算作0点，对手没有手牌时直接造成3点伤害。
  - 进攻0️⃣由 RedFlag 决定保留或更换自己的剩余手牌。AI 扮演 RedFlag 时，如果剩余手牌中没有可继续打出的牌，就会更换。

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 格挡2🛡️，对手有[失温]时，额外反击2🗡️ |
| 2️⃣ | 恢复1❤️，施加[失温]，抽1🃏 |
| 0️⃣ | 反击相同伤害🗡️，进攻方从自己的手牌中选择一半弃掉（向上取整）。冒险 NPC 优先弃掉保留优先级低的牌 |

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
