# 🐺 RedFlag

- **初始血量**：60
- **被动**：

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 抽1🃏，施加[失温] |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 4🗡️，目标有[失温]时变为不可防御 |
| 4️⃣ | 对手每有一张手牌，造成1🗡️，伤害 < 4时施加[失温] |
| 5️⃣ | 抽取对手1牌，造成对应数字+3🗡️，然后弃掉该牌 |
| 0️⃣ | 7🗡️，对手防御之前可以决定：是否要弃掉所有手牌并重新抽取相同数量🃏 |

- 备注：
进攻4️⃣，伤害数值计算，依照打出进攻牌，对手打出防御牌之前的对手手牌数。
进攻5️⃣，冒险模式下由玩家选择对手手牌，其余模式由系统随机抽取（选中的牌放入判定区展示，防御结束后再进入弃牌库），没有点数的牌算作0点。
