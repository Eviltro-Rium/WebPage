# 🐼 Moze

- **初始血量**：100
- **被动**：每次受到伤害时，可选择消耗若干层【守护】来减免最终受到的伤害，每消耗1层【守护】减免1🗡️。【守护】不能减免【流血】的伤害。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 3🗡️ |
| 2️⃣ | 2🗡️，获得1层【守护】；若打出的牌是🟢则再获得1层【守护】 |
| 3️⃣ | 1🗡️，恢复1❤️，获得1层【守护】 |
| 4️⃣ | 打出1张数字牌（对应技能不生效），获得对应数字层【守护】，然后弃掉该牌（跳过防御） |
| 5️⃣ | 从攻击目标手牌中抽取1🃏（入判定区），若为🟢/⚪/⚫→4🗡️；否则→恢复2❤️，获得1层【守护】（跳过防御）。无论判定如何都要将该牌加入自己手牌 |
| 6️⃣ | 造成2+【守护】层数🗡️；如果没有【守护】则变为不可防御 |
| 7️⃣ | 3🗡️，清除所有debuff，每清除1层debuff+1🗡️ |
| 0️⃣ | 获得3层【守护】，5🗡️，抽1🃏 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 🛡️½（向上取整）🗡️，获得1层【守护】 |
| 2️⃣ | 反击1+½×【守护】层数（向上取整）🗡️ |
| 3️⃣ | 获得1层【守护】，恢复1/2*【守护】层数（向上取整）❤️ |
| 0️⃣ | 🛡️½（向上取整）🗡️，获得2层【守护】，反击2×【守护】层数🗡️ |

## 举例

对方造成9🗡️，Moze有3层【守护】，Moze打出0️⃣🛡️½（5🗡️），获得2层【守护】（共5层），反击2×5=10🗡️。防御结算后，Moze选择消耗4层【守护】来免去4🗡️，Moze最终受到0🗡️。如果Moze有【流血】仍需额外受到【流血】层数🗡️。

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
