# 🐼 Moze

- **初始血量**：100
- **被动**：可以给队友使用【守护】，但给队友使用时，使用不能超过2个。

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 1🗡️（不可防御），恢复1❤️，获得1层【守护】 |
| 2️⃣ | 2🗡️，获得1层【守护】；若打出的牌是🟢则再获得1层【守护】 |
| 3️⃣ | 3🗡️ |
| 4️⃣ | 打出1张数字牌（对应技能不生效），获得对应数字层【守护】，然后弃掉该牌（跳过防御） |
| 5️⃣ | 从攻击目标手牌中抽取1🃏，若为🟢/⚪/⚫→4🗡️；否则→恢复2❤️，获得2层【守护】（跳过防御）。（冒险模式由玩家选择，其他模式系统随机抽取；入判定区，对手没有卡牌时走恢复分支） |
| 6️⃣ | 造成3+【守护】层数🗡️；如果没有【守护】则变为不可防御 |
| 7️⃣ | 3🗡️，选择清除自己所有负面buff或清除对手所有正面buff，每清除1层debuff+1🗡️ |
| 0️⃣ | 获得3层【守护】，6🗡️，抽1🃏 |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 防御1/2🛡️（向上取整），获得1层【守护】 |
| 2️⃣ | 反击1+½×【守护】层数（向上取整）🗡️ |
| 3️⃣ | 获得1层【守护】，恢复1/2*【守护】层数（向上取整）❤️ |
| 0️⃣ | 防御1/2🛡️（向上取整），获得2层【守护】，反击2×【守护】层数🗡️ |

## 举例

对方造成9🗡️，Moze有3层【守护】，Moze打出0️⃣，防御1/2🛡️（5🗡️），获得2层【守护】（共5层），反击2×5=10🗡️。防御结算后，Moze选择消耗4层【守护】来免去4🗡️，Moze最终受到0🗡️。如果Moze有【流血】仍需额外受到【流血】层数🗡️。

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
