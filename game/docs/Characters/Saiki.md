# 🐺 Saiki

- **初始血量**：60
- **被动**：⚔️阶段打出🟡牌（含指定为黄色的白牌/黑牌），对对手施加（防御之后）1层[流血]（流血：最多3层，有该debuff的角色触发防御技能时受到1🗡️额外独立伤害）

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 2🗡️，施加2层[流血] |
| 2️⃣ | 4🗡️ |
| 3️⃣ | 5🗡️，若对手有[流血]则不可防御 |
| 4️⃣ | 若❤️≤30→恢复4❤️，施加[流血]；否则4🗡️，弃掉对手1🃏（冒险模式由玩家选择、其他模式系统随机抽取）|
| 5️⃣ | 吸取3+对手[流血]层数❤️（不可防御） |
| 0️⃣ | 对手防御后先施加1层[流血]，再造成2×对手[流血]层数+3🗡️，随后恢复场上[流血]层数之和❤️ |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 反击3🗡️，之后施加1层[流血] |
| 2️⃣ | 翻开牌库顶1张判定：🟡/⚫/⚪→防御所有伤害🛡️（不免疫⬇️debuff）；否则无效，判定牌加入手牌 |
| 0️⃣ | 防御所有伤害🛡️，免疫⬇️debuff，双方均摊1/2（向上取整）🗡️，debuff反弹给进攻者 |

## Emoji 说明

| Emoji | 含义 |
|-------|------|
| 🗡️ | 伤害点数 |
| ❤️ | 恢复生命值 |
| 🛡️ | 格挡/防御 |
| 🃏 | 卡牌 |

Buff 与 Debuff 详细说明见 [buff_guide.md](../reference/buff_guide.md)。
