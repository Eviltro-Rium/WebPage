# 🐺 Saiki

- **初始血量**：80
- **被动**：⚔️阶段打出🟡牌（含指定为黄色的白牌/黑牌），对对手施加1层【流血】（最多3层，有该debuff的角色触发防御技能时受到1🗡️额外独立伤害）

## ⚔️ 进攻阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 4🗡️ |
| 2️⃣ | 3🗡️，恢复1❤️ |
| 3️⃣ | 2🗡️，抽对手手牌1🃏（可选择弃掉或加入手牌） |
| 4️⃣ | 5🗡️，若对手有【流血】则不可防御 |
| 5️⃣ | 若❤️≤20→恢复4❤️；若20<❤️≤50→4🗡️跳过防御；若❤️>50→4🗡️+抽对手1🃏 |
| 6️⃣ | 再打1张数字🃏入判定区，对应点数×1.5（向上取整）🗡️，若为🟡牌施加1层【流血】，判定牌放入弃牌库底 |
| 7️⃣ | 吸取3+对手【流血】层数❤️ |
| 0️⃣ | 施加1层【流血】，3×对手【流血】层数+1🗡️，恢复双方【流血】层数之和❤️ |

## 🛡️ 防御阶段

| 牌 | 效果 |
|---|------|
| 1️⃣ | 🛡️至多3🗡️ |
| 2️⃣ | 2🗡️，⚔️结束后施加1层【流血】 |
| 3️⃣ | 翻开牌库顶1张判定：🟡/⚫/⚪→🛡️所有🗡️（不免疫⬇️debuff）；否则无效，判定牌加入手牌 |
| 0️⃣ | 🛡️所有🗡️，免疫⬇️debuff，双方均摊½（向上取整）🗡️，debuff反弹给进攻者 |

## Emoji 说明

- 🗡️ = 伤害点数
- ❤️ = 恢复生命值
- 🛡️ = 格挡/防御
- 🃏 = 卡牌
- Buff 与 Debuff 详细说明见 [buff_guide.md](../buff_guide.md)
