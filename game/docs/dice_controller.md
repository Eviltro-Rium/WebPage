# 遥控骰子与D12判定边界

- 原始骰面统一由 Engine.rollD12 产生；掉落规则接收该骰面，不再另掷一次。
- AdventureDiceController 是冒险专用适配器，不改变单机普通模式或在线对决。
- 同步技能在入口动作内记录随机数并暂存定时器。遇到可遥控的D12时暂停，进入 DICE_CHOICE；副作用尚未结算。
- 待选择记录包含入口方法、参数、JSON战斗检查点、随机数序列和已确认骰面；不存闭包。选择后从检查点续算同一动作，使用相同随机数，只替换选定骰面。
- 出牌、抽牌、伤害、道具消耗及掉落不会累计两次；已播放的事件按事件ID去重。下一次骰子仍可单独选择。
- 定时器只在动作完成后提交，等待期间其他动作被阻止；clearEvents 只确认动画，不推进伤害结算。
- 战斗存档包含待选择记录，刷新可继续；旧存档和无道具时直接走原引擎路径，没有检查点开销。
- 遥控骰子遵循致盲限制，在全宽底部弹出卡片中选择保留结果或指定1–12骰面；判定区继续显示原骰面供参考。商店和图鉴通过道具注册表自动发现。
- 遥控待选时事件带 `awaitControl`：D12 翻滚走 `fast`（约 240ms）、投后等待约 40ms；动画一开始即可开选面面板，尽快进入/保持 `DICE_CHOICE`。

## 魔术师配饰（`Magician`）

- 配饰，上限 1；与一次性道具「遥控骰子」**互斥**（不能同时生效/持有）。
- 在 D12 出结果后可将骰面 **±1**（夹紧 1–12）；每次调整消耗 **3 点生命**（保留原结果不扣血）。
- 顺序：**先遥控骰子，再魔术师**。详见 [adventure_guide/accessories.md](adventure_guide/accessories.md)。
