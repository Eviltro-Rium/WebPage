# 在线对决观战席方案

已接入在线模式。房间协议 v3 使用信令服务传送观战快照。每个房间设两个对战席和一个只读观战席。

## 入座与开局

- 房主创建房间时固定占一个对战席。其他人在等待房间自行选「对战」或「观战」，也可以在开局前换到空席。席位已满时显示占用状态。两人同时抢最后一个席位，由信令 Worker 确认归属后再更新界面。
- 离开对战席时清除该席的选角和准备状态。开局只检查两个对战席是否已经选角并准备，由房主开始。观战席可以空着，观众无需选角或准备。
- 对局开始后锁定对战席。观战席空闲时允许中途加入，入座后直接显示最新战况。

## 观战画面

复用现有战斗布局。仅在观战视角移除上方原有的对手手牌区，在战场下方从上到下排列「房主手牌」「客方手牌」，各自标明昵称。两排同时显示当前手牌的完整牌面，出牌、抽牌和弃牌动画对应各自的手牌区。观众可查看牌面说明，战斗操作只对参战者开放。参战视角沿用原来的上下布局和手牌可见规则。

## 同步与断线

- 两位参战者继续通过现有 P2P 或中继通道同步。房主从同一战斗状态生成观战快照，经 Worker 定向发送到观战席。快照包含双方手牌和战场信息，排除未抽取的牌库顺序、待提交的选择及重连令牌。Worker 按已确认的席位路由消息，拒绝观众发起战斗指令或开局请求。
- 观众加入或刷新时先收取当前快照，再按对局 ID 和状态版本接收更新。观众的动画播放和事件确认不参与战斗推进。
- 对局中，主动退出立即计为离席。意外掉线沿用现有 15 秒重连窗口，期限内恢复即保留席位。仅一名参战者离开时，观众显示该方的连接状态。两名参战者均已离席或重连超时后，由 Worker 通知观众、关闭房间。观战端清除房间会话并自动返回联机入口。该清理需能在房主离线时独立执行，观众也不能被递补为房主。

## 验收场景

| 操作 | 预期结果 |
| --- | --- |
| 两名参战者准备，观战席空置或已入座 | 两种情况下房主都能立即开局 |
| 客方在等待房间由已准备的对战席转入观战席 | 对战席腾空，原准备状态清除，房主不能转入观战席 |
| 观众中途入场，随后双方各抽牌、出牌 | 下方两排手牌与实际牌面一致，上方没有重复手牌区，参战者只能看到各自手牌的牌面 |
| 观众刷新或退出 | 对局继续，刷新后能恢复到最新战况 |
| 一人退出，另一人掉线后在期限内重连 | 观众留在房间 |
| 双方主动退出、双方掉线超时，或一人退出且另一人掉线超时 | 观众自动退回联机入口，刷新后也不会重入已关闭的房间 |
