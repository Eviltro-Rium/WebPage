### 出牌规则

- 出牌需匹配弃牌库顶牌的**颜色**或**数字**
- 黑牌和白色道具牌可匹配任意颜色（万能牌）
- 黑牌和白牌指定颜色后，按对角线渐变渲染（左上原色→右下指定颜色）

---

### 搭桥机制

出以下牌时不会结束出牌，而是进入搭桥状态：

| 搭桥牌 | 效果 |
|--------|------|
| ⚫ 黑牌 | 选择一种颜色，继续出牌 |
| ⚫ 黑+2 | 选择一种颜色，抽2张，继续出牌 |
| ⚫ 洗入 | 选择一种颜色，弃牌库除顶牌外洗入牌库，继续出牌 |
| 🧪 | 恢复5❤️，继续出牌 |
| +3🃏 | 抽3张牌，继续出牌 |
| ✨ | 净化1层debuff，继续出牌 |
| ✨✨ | 选择一名角色，清除其所有buff与debuff(含🛡️守护)，继续出牌 |
| 🔄 | 交换双方所有手牌，继续出牌 |

搭桥可连续使用（如：黑牌→🧪→+3→✨→黑牌…），直到出一张数字牌或选择不出为止。

---

### 防御规则

- 被攻击时可出一张**数字≤3**且颜色匹配的牌进行防御
- 防御也可搭桥：出黑牌/🧪/+3🃏/✨/✨✨/🔄后继续出防御牌
- 不防御则承受全部伤害

---

### 净化机制

- **✨ 净化牌**：移除1层debuff（灼烧/冷冻/流血中自选1项）
- **✨✨ 超级净化牌**：选择一名角色（自己或对手），清除其所有buff与debuff，包括正面buff（🛡️守护）

---

### 牌的分类

| 分类 | 包含 | 说明 |
|------|------|------|
| 数字牌 | 🔴🟡🔵🟢 0~7、⚪ 白1~白7 | 有具体数字的牌 |
| 道具牌 | ⚫ 黑牌、⚫ 黑+2、⚫ 洗入、⚪ 🧪、⚪ +3🃏、⚪ ✨、⚪ ✨✨、⚪ 🔄 | 无数字或特殊功能的牌 |

> 数字牌和道具牌互斥：一张牌不可能同时是数字牌和道具牌。

## 二、冒险模式牌库配置

### 玩家牌库（`makePlayerDeck`）

冒险模式玩家使用完整 UNO 风格牌组，**不含交换手牌（🔄）**：

| 类型 | 数量 | 说明 |
|------|------|------|
| 四色数字牌（0~7） | — | 红黄蓝绿各 1×0、3×1~3、2×4~6、1×7 |
| 白色数字牌（1~7） | 各1张，共7张 | 匹配任意颜色 |
| ⚫ 黑牌 / 黑+2 / 🧪 | 各2张 | 搭桥道具牌 |
| ⚫ 洗入 / ⚪ +3🃏 | 各2张 | 搭桥道具牌 |
| ⚪ ✨（净化）/ ⚪ ✨✨（超级净化） | 各4张 | 净化道具牌 |

> 冒险模式**不含** 🔄 交换手牌牌。

**手牌上限**：5 张

---

### 怪物 / NPC 牌库（`makeNpcDeck`）

所有怪物使用纯白色牌库，牌面为白色，数字独立于弃牌库顶牌：

| 牌面 | 普通怪物 | Boss |
|------|----------|------|
| 白 0 | 0 张 | 2 张 |
| 白 1/2/3 | 各 5 张 | 各 5 张 |
| 白 4/5/6 | 各 3 张 | 各 3 张 |
| 🟣 魔法牌（紫色） | 2 张 | 2 张 |
| 🟢 绿魔法牌 | 2 张 | 2 张 |

**怪物白牌渲染**：主体颜色与普通白牌相同，区分细节为：右上/左下角紫色 L 形括弧 + 右下角紫色小骷髅图标。

**手牌上限**：

| 类型 | 默认上限 |
|------|----------|
| 普通怪物 | 2 张（可被 `handLimit` 覆盖） |
| Boss | 3 张 |
| 特殊怪物（如森林水豚、大王花） | 3 张（`handLimit: 3`） |

### 牌库实现索引

| 内容 | 文件 / 函数 |
|------|-------------|
| 玩家牌库生成 | `adventure/js/deck/adventure_deck.js` → `makePlayerDeck()` |

| 怪物属性（手牌上限/白0数量） | 各 `adventure/js/monsters/*.js` 中的 `registerMonster()` 调用 |

### 场景怪物池配置

怪物按场景和 Stage 分阶段配置池，战斗时从对应池中随机抽取：

| 场景 | 怪物池文件 |
|------|-----------|
| 城堡 | `adventure/js/monsters/castle.js` → `AdventureMonsterPool.castle` |
| 丛林 | `adventure/js/monsters/forest.js` → `AdventureMonsterPool.forest` |
| 冻洋 | `adventure/js/monsters/ocean.js` → `AdventureMonsterPool.ocean` |

各场景怪物池按 Stage 逐级扩充（Stage 2/3/4 开放更多怪物）。
