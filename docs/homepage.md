## 常驻共享背景

个人网站的五个入口通过 `js/site-navigation.js` 进入 `site-shell.html` 宿主。宿主只初始化一次 Three.js 和山丘场景，正文在透明的命名 iframe 中切换，避免替换 DOM 后重复注册相册/音频等脚本。正文页不再加载 Three.js 与背景脚本；游戏维持原独立入口，普通点击会跳出宿主。

内部页面导航保留 URL（file:// 不允许跨文件 History API 时使用宿主 hash 回退），支持刷新与前进后退。导航消息仅接受当前正文窗口，目标限制为本站同目录的五个页面。Ctrl/Cmd 点击、新标签页和外部链接沿用浏览器行为。正文滚动不影响背景，切换正文会自然销毁旧页音频上下文；当前配色由正文的原主题事件同步给宿主背景。

验证：真实 Chromium 在 HTTP 下完整循环五页，背景 canvas 与 Three 对象身份始终一致，正文 canvas 数为 0；后退与主题同步通过，无脚本异常。file:// 验证直接进入资料页、切换作品、刷新保留当前页、进入游戏退出宿主均通过。共享宿主的脚本顺序与正文不重复加载背景由 `game/tests/home-loading-progress.test.js` 检查。

## 页面切换过渡

共用宿主在导航时对正文 iframe 进行 140ms 淡出，再在新正文 DOMContentLoaded 就绪后进行 320ms 淡入和 10px 轻微上移，背景画布不参与动画。减少动态效果时直接切换。

退场期间连续导航只提交最后一次目的地与历史记录；就绪消息同时校验发送窗口和当前 URL，忽略过期页面消息。8 秒超时后释放透明及忙碌状态。导航监听提前到头部解析阶段，避免资源未加载完时点击链接绕过宿主。

验证：`node --test game/tests/site-navigation.test.js` 覆盖连续导航、过期消息、超时与目标白名单；真实浏览器验证五页循环、背景实例不变、历史后退、主题同步、快速连点只新增一条历史及减少动态效果。file:// 的导航、刷新和游戏跳出宿主复验通过。基础检查 333 项通过。
